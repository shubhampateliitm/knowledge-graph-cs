# problem-map backbone concepts
prefixsums > calculus | A prefix sum is a discrete integral and a difference array is a discrete derivative.
prefixsums > bigo | One O(n) pass of precomputation makes every later range query O(1).
twopointers > ordertheory, proofs | Moving a pointer is safe because sorted order proves the skipped pairs cannot be better.
twopointers > sorting | Most two-pointer scans first sort the input, then walk it from both ends or in step.
binsearch > ordertheory, asymptotics | Bisection needs a monotone condition over an ordered set and takes about log2 n steps.
binsearch > sorting | Searching by halves needs the data sorted, or a monotone test over the answer space.
monostack > ordertheory | The stack keeps its items in sorted order; a new item pops everything it beats.
monostack > queuesbuf, amortized | It is a stack or deque in which each item is pushed and popped once, so the total work is linear.
linkedlist > graphtheory | A singly linked list is a path graph; cycle detection on lists is cycle detection on a functional graph.
linkedlist > vonneumann | Each node holds a value and the memory address of the next node.
mst > graphtheory | Spanning trees and the cut property are graph-theory results.
mst > graphsalgo, unionfind, greedydc | Kruskal is a greedy edge scan that uses union-find to reject cycles; Prim is a heap-driven graph search.
lca > graphtheory | Ancestors, depths and paths in a rooted tree are graph-theory notions.
lca > trees, rangeq, binary | Jump tables of 2^k-th ancestors follow the binary digits of a distance; the Euler-tour method uses a range-minimum table.
combgames > gametheory, settheory, boolalg, proofs | Winning positions are defined by induction on moves, Grundy values use the minimum excluded value of a set, and game sums combine by XOR.
rangeq > prefixsums | Fenwick and segment trees are prefix sums made updatable.
compgeom > prefixsums | Line sweeps keep running counts of open intervals, a difference array in sorted order.
startree > prefixsums | Star-tree nodes store pre-aggregated totals, so a query adds a few stored sums instead of scanning rows.
joins > twopointers | Sort-merge join walks both sorted inputs with one pointer each.
windowing > twopointers | A sliding window adds events at its head and evicts them at its tail as time moves.
ratelimit > twopointers | A sliding-window limiter keeps recent requests in a window and drops those that fall out of it.
btree > binsearch | A lookup binary-searches the sorted keys inside each node.
segments > binsearch | Finding a message by offset binary-searches the sparse offset index.
git > binsearch | git bisect binary-searches the commit history for the first bad commit.
windowing > monostack | Sliding-window min and max aggregates keep a monotonic deque of candidates.
compgeom > monostack | Andrew's monotone chain builds a convex hull with a stack that pops points making the wrong turn.
eviction > linkedlist | An LRU cache keeps entries in a doubly linked list ordered by recency, next to a hash map.
bufferpool > linkedlist | Free frames and the replacement order of pages are kept on linked lists.
allocators > linkedlist | Free blocks of each size class sit on linked free lists.
queuesbuf > linkedlist | A skip list is a sorted linked list with extra express levels.
clustering > mst | Single-linkage clustering is Kruskal's algorithm stopped before the last k-1 merges.
approxalgo > mst | Doubling a minimum spanning tree gives a 2-approximation for the metric travelling salesman.
git > lca | git merge-base finds the lowest common ancestor of two commits in the history graph.
mcts > combgames | MCTS searches the game tree of two-player perfect-information games such as Go.
