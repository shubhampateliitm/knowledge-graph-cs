# Concepts added from the Stanford BS/MS curriculum (CS 103–CS 336) and from official product documentation (Oct 2026).
# id | label | category | year | status | mechanism
## L1
declpipelines | Declarative pipelines & materialized views | Data engineering | 2022 | Spark Declarative Pipelines (4.1), Delta Live Tables, dbt, Materialize | You declare which tables should exist and how each is derived; the engine builds the dependency graph and keeps them up to date incrementally.

## L2
sharegroups | Share groups (queues on Kafka) | Streaming | 2025 | Kafka share groups (KIP-932), production-ready in Kafka 4.2 (Feb 2026) | Many consumers read the same partition; each record is locked to one consumer and individually acknowledged, released or rejected.
rowlineage | Row lineage & change feeds | Storage engines | 2023 | Iceberg v3 row lineage; Delta row tracking and change data feed | Each row gets a stable ID and the version that last changed it, so engines can read only what changed.
vr | Viewstamped replication | Distributed systems | 1988 | | A primary orders requests and backups follow; a view change elects a new primary from a majority. Raft's direct ancestor.
lsh | Locality-sensitive hashing | Algorithms | 1998 | | Hash functions where similar items are likely to collide, so near-duplicates land in the same bucket.
suffixarrays | Suffix arrays & suffix trees | Algorithms | 1990 | | Every suffix of a text, sorted; any substring is a prefix of some suffix, so search is a binary search.
unionfind | Union–find (disjoint sets) | Algorithms | 1964 | | Each set is a tree pointing to a representative; path compression makes operations nearly constant time.
cuckoo | Cuckoo hashing & cuckoo filters | Algorithms | 2001 | | Each key has two possible slots; inserting may evict a key to its other slot, giving worst-case O(1) lookups.
rangeq | Range-query structures (RMQ, segment & Fenwick trees) | Algorithms | 1994 | | Precompute partial answers over intervals so range sums or minimums take O(log n) or O(1).
workstealing | Work stealing | Performance | 1994 | Cilk, Java ForkJoin, Rust Rayon, Go scheduler | Each worker has a deque of tasks; idle workers steal from the far end of busy workers' deques.
lockfree | Lock-free data structures | Performance | 1991 | | Updates use compare-and-swap loops instead of locks; memory reclamation (hazard pointers, epochs) avoids the ABA problem.
regression | Linear & logistic regression (GLMs) | Machine learning | 1805 | | Fit a weighted sum of features to predict a number, or pass it through a sigmoid to predict a probability.
svm | Kernels & support vector machines | Machine learning | 1992 | | Find the boundary with the widest margin; the kernel trick does this in a high-dimensional feature space implicitly.
clustering | Clustering & EM (k-means, GMMs) | Machine learning | 1957 | | Alternate between assigning points to clusters and re-fitting each cluster; EM does the soft, probabilistic version.
pca | PCA & dimensionality reduction | Machine learning | 1901 | | Project data onto the few directions of greatest variance, found by the singular value decomposition.
vae | Variational autoencoders | Deep learning & LLMs | 2013 | | An encoder maps data to a distribution over latent codes and a decoder maps codes back, trained by maximizing the ELBO.
flows | Normalizing flows | Deep learning & LLMs | 2015 | | Chain invertible transformations whose Jacobians are cheap, so exact likelihoods can be computed.
gans | Generative adversarial networks | Deep learning & LLMs | 2014 | | A generator tries to fool a discriminator that tries to tell real from fake; both improve together.
qlearning | Q-learning & DQN | Reinforcement learning | 1989 | | Learn the value of each action in each state from experience by bootstrapping on the best next action.
policygrad | Policy gradients & PPO | Reinforcement learning | 1992 | | Increase the probability of actions that led to higher-than-expected reward; PPO limits each update's size.
mcts | Monte Carlo tree search | Reinforcement learning | 2006 | | Grow a search tree by simulating games from promising moves and backing up results; AlphaGo combined it with networks.
bandits | Multi-armed bandits | Reinforcement learning | 1933 | | Balance trying options (explore) with using the best so far (exploit), e.g. Thompson sampling or UCB.
pagerank | PageRank & link analysis | Algorithms | 1998 | | A page's importance is the probability a random surfer is there: the stationary distribution of a Markov chain.
matfact | Matrix factorization (collaborative filtering) | Machine learning | 2006 | | Approximate the sparse user × item matrix as a product of two thin matrices of user and item factors.
chunkedprefill | Chunked prefill & disaggregated serving | ML systems | 2023 | vLLM, SGLang, TensorRT-LLM | Split long prompts into chunks interleaved with decode steps, or run prefill and decode on different GPUs.
mlcompilers | ML compilers (torch.compile, XLA, Triton) | ML systems | 2017 | | Capture a model as a graph, fuse operations and generate GPU kernels tuned to the hardware.
concgc | Generational & concurrent GC (G1, ZGC) | Performance | 1984 | Java 25: G1 default; ZGC is generational-only since JDK 24 (JEP 490); generational Shenandoah is a product feature in JDK 25 (JEP 521) | Collect young objects often and cheaply; mark and move old objects while the program runs, using barriers.
interp | Interpretability | Deep learning & LLMs | 2017 | | Look inside trained networks to find the features and circuits that produce their behaviour.
adversarial | Adversarial examples & robustness | Deep learning & LLMs | 2013 | | Tiny, targeted input changes can flip a model's output; robustness methods train or certify against them.

## L3
pagereplace | Demand paging & page replacement | Operating systems | 1962 | | Load pages only when touched; when memory is full, evict a page chosen by an approximation of LRU (the clock algorithm).
fsjournal | File-system journaling | Operating systems | 1990 | ext4, XFS, NTFS | Write intended metadata changes to a journal first, then apply them, so a crash never leaves the file system half-updated.
condvars | Condition variables & monitors | Operating systems | 1974 | | A thread waits on a condition while releasing its lock; another thread signals when the condition may be true.
roofline | Roofline model & arithmetic intensity | Computer architecture | 2009 | | Performance is capped by peak compute or by memory bandwidth × FLOPs per byte, whichever is lower.
rpc | Remote procedure calls & serialization | Computer networks | 1984 | gRPC, Thrift, Protobuf, Avro | Make a network call look like a function call: serialize arguments, send, wait, deserialize the result.
bgp | BGP & internet routing | Computer networks | 1989 | | Networks (autonomous systems) announce which address blocks they can reach; each picks paths by policy.
nat | NAT & firewalls | Computer networks | 1994 | | Rewrite private addresses and ports to a shared public one, and track connections to filter traffic.
maxflow | Network flow & matching | Algorithms & data structures | 1956 | | Push flow along augmenting paths until none remain; the maximum flow equals the minimum cut.
randalgo | Randomized algorithms | Algorithms & data structures | 1976 | | Use random choices to get simple algorithms with good expected or high-probability guarantees.
streamalgo | Streaming & sketching algorithms | Algorithms & data structures | 1985 | | Process a huge stream in one pass with tiny memory, keeping a summary (sketch) that answers approximately.
regalloc | Register allocation | Programming languages & compilers | 1981 | | Assign many program variables to few CPU registers by colouring an interference graph; spill the rest to memory.
dataflowan | Dataflow analysis & optimization | Programming languages & compilers | 1973 | | Compute facts (live variables, constants) at each program point by iterating to a fixed point over the control-flow graph.
aead | Authenticated encryption (AEAD) | Cryptography | 2000 | AES-GCM, ChaCha20-Poly1305 | Encrypt and authenticate in one step, so any tampering is detected; nonces must never repeat.
pqcrypto | Post-quantum (lattice) cryptography | Cryptography | 2005 | NIST FIPS 203/204/205 (Aug 2024); HQC selected as backup KEM (Mar 2025) | Security rests on hard lattice problems (learning with errors) that quantum computers are not known to solve.
zkp | Zero-knowledge proofs | Cryptography | 1985 | | Prove a statement is true (I know a secret, this computation is correct) without revealing anything else.
controlhijack | Memory-safety bugs & control hijacking | Security | 1988 | | Overflow a buffer to overwrite a return address or function pointer and redirect execution.
exploitmit | Exploit mitigations (ASLR, DEP, canaries, CFI) | Security | 2000 | | Randomize memory layout, forbid executing data, detect smashed stacks and restrict indirect jumps.
websec | Web security (same-origin, XSS, CSRF) | Security | 1995 | | Browsers isolate sites by origin; attacks try to run script in another origin or forge requests with its cookies.

## L4
lp | Linear programming & duality | Continuous math | 1947 | | Optimize a linear objective under linear constraints; every maximum problem has a dual minimum with the same value.
mdp | Markov decision processes & Bellman equations | Probability & statistics | 1957 | | States, actions, rewards and transitions; the value of a state equals the best immediate reward plus the discounted value of what follows.
concentration | Concentration inequalities (Chernoff, Hoeffding) | Probability & statistics | 1952 | | Sums of many independent random variables stay very close to their mean with exponentially high probability.
jl | Random projections & the JL lemma | Continuous math | 1984 | | Projecting points onto a random low-dimensional subspace keeps all pairwise distances nearly the same.
convexity | Convexity & Jensen's inequality | Continuous math | 1906 | | A convex function's average is at least the function of the average; convex problems have no bad local minima.
