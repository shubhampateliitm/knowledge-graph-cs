prefixsums | Prefix sums & difference arrays | Algorithms & data structures | 1962 | APL scan (+\), NumPy cumsum, SQL SUM() OVER window frames, summed-area tables in graphics | Store the running total of an array once, so any range sum is one subtraction of two stored totals; to add a value to a whole range, write +v at its start and -v after its end in a difference array and take one prefix sum at the end.
twopointers | Two pointers & sliding windows | Algorithms & data structures | | Merge step of merge sort, sort-merge joins, sliding-window rate limiters and stream windows | Two indexes move through a sequence in one direction each, and every step one of them moves past an item that can never be part of a better answer, so a quadratic search over pairs or ranges becomes one linear pass.
binsearch | Binary search & bisection | Algorithms & data structures | 1946 | Python bisect, C++ lower_bound, git bisect, B-tree node and SSTable index lookups | When a yes/no condition is false and then true along a sorted range (an array, or the space of possible answers), test the middle and throw away the half that cannot hold the boundary, so n candidates need only about log2 n tests.
monostack | Monotonic stacks & queues | Algorithms & data structures | | Sliding-window min/max in stream processors, Andrew's monotone-chain convex hull, stock-span analytics | Keep a stack (or deque) whose values stay sorted by popping every item the new one beats; each popped item has just met its next greater or smaller element, and since each item is pushed and popped once the whole scan is linear.
linkedlist | Linked lists | Algorithms & data structures | 1956 | Linux kernel list_head, LRU lists in caches and buffer pools, allocator free lists, skip lists | Each node stores a value and the address of the next node (and, in a doubly linked list, the previous one), so inserting or removing a known node is a constant-time pointer change while reaching the k-th node takes k steps.
mst | Minimum spanning trees | Algorithms & data structures | 1926 | Network design, single-linkage clustering, 2-approximation for metric TSP | Pick the cheapest set of edges that connects every node with no cycle: Kruskal sorts edges and keeps each one unless union-find says its ends are already joined, Prim grows one tree by always taking the cheapest edge leaving it; both rest on the cut property.
lca | Lowest common ancestor & binary lifting | Algorithms & data structures | 1973 | git merge-base, phylogenetic trees, tree-distance queries in hierarchies | Precompute each node's depth and its 2^k-th ancestors (or an Euler tour with a range-minimum table), then lift two nodes to the same depth and jump up together by decreasing powers of two until their parents meet, answering each query in O(log n).
