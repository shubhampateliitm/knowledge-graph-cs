@@ bs2arrays
what: To find the median of two sorted arrays, we cut each array in two so the left parts together hold half of all items. We only search how many items i to take from the shorter array; the other cut j follows from i. The cut is right when every left item is at most every right item, and that needs only two comparisons across the cuts. Binary search on i gives O(log(min(m, n))), better than merging.
signals: median of two sorted arrays ; O(log (m+n)) time is required ; k-th smallest across two sorted lists ; two sorted inputs and you must not merge them

```python
def find_median_sorted_arrays(nums1: list[int], nums2: list[int]) -> float:
    a, b = nums1, nums2
    if len(a) > len(b):
        a, b = b, a                    # search on the shorter array
    m, n = len(a), len(b)
    half = (m + n + 1) // 2            # size of the left part
    lo, hi = 0, m
    while lo <= hi:
        i = (lo + hi) // 2             # items taken from a
        j = half - i                   # items taken from b
        a_left = a[i - 1] if i > 0 else -inf
        a_right = a[i] if i < m else inf
        b_left = b[j - 1] if j > 0 else -inf
        b_right = b[j] if j < n else inf
        if a_left > b_right:
            hi = i - 1                 # took too many from a
        elif b_left > a_right:
            lo = i + 1                 # took too few from a
        else:
            if (m + n) % 2:
                return float(max(a_left, b_left))
            return (max(a_left, b_left) + min(a_right, b_right)) / 2
    return 0.0
```

what: A binary search tree keeps smaller keys on the left and larger keys on the right. To insert, walk down choosing a side until you reach an empty spot, and put the new node there.         return TreeNode(val)           # empty spot: new node goes here
```python
    if val < root.val:
        root.left = insert_into_bst(root.left, val)
    else:
        root.right = insert_into_bst(root.right, val)
    return root

def delete_node(root: Optional[TreeNode], key: int) -> Optional[TreeNode]:
    if root is None:
        return None
    if key < root.val:
        root.left = delete_node(root.left, key)
    elif key > root.val:
        root.right = delete_node(root.right, key)
    else:

        if root.right is None: return root.left
        nxt = root.right               # successor: leftmost of right subtree
        while nxt.left:
            nxt = nxt.left
        root.val = nxt.val
        root.right = delete_node(root.right, nxt.val)
```

@@ bstinorder
what: An inorder walk visits left, then the node, then right. In a BST this yields the keys in sorted order. So any trick that works on a sorted array works while you walk, if you remember the previous key. You get sorted order without copying the keys into a list.
signals: BST and minimum difference between nodes ; k-th smallest in a BST ; check that a tree is a valid BST ; find or fix two swapped values in a BST ; convert a BST to a sorted list or a greater tree

```python
def get_minimum_difference(root: Optional[TreeNode]) -> int:
    best = float("inf")
    prev = None                        # previous key in sorted order

    def walk(node: Optional[TreeNode]) -> None:
        nonlocal best, prev
        if node is None:
            return
        walk(node.left)                # smaller keys first
        if prev is not None:
            best = min(best, node.val - prev)
        prev = node.val
        walk(node.right)               # larger keys last

    walk(root)
    return best
```

@@ morris
what: Morris traversal walks a tree in inorder without a stack or recursion. Before going left, find the inorder predecessor of the node and make its empty right pointer point back to the node. When the walk returns through that link, we know the left side is done, so we remove the link and move right. Each edge is walked at most twice, so the time is still O(n) but the extra space is O(1).
signals: O(1) extra space is required ; traverse a tree without recursion or a stack ; fix or check a BST in constant space ; the tree must be restored to its original shape
code:
```python
def recover_tree(root: Optional[TreeNode]) -> None:
    first = second = prev = None
    cur = root
    while cur:
        if cur.left is None:
            visit = cur
            cur = cur.right
        else:
            pred = cur.left            # inorder predecessor of cur
            while pred.right and pred.right is not cur:
                pred = pred.right
            if pred.right is None:
                pred.right = cur       # make a temporary link back
                cur = cur.left
                continue
            pred.right = None          # link seen again: remove it
            visit = cur
            cur = cur.right
        if prev and prev.val > visit.val:   # order broken here
            if first is None:
                first = prev
            second = visit
        prev = visit
    first.val, second.val = second.val, first.val
```

```python
def distance_k(root: TreeNode, target: TreeNode, k: int) -> list[int]:
    parent = {}

    def link(node: Optional[TreeNode], par: Optional[TreeNode]) -> None:
        if node:
            parent[node] = par         # remember the way up
            link(node.left, node)
            link(node.right, node)

    link(root, None)
    queue, seen = deque([target]), {target}
    for _ in range(k):                 # one BFS layer per step
        for _ in range(len(queue)):
            node = queue.popleft()
            for nb in (node.left, node.right, parent[node]):

                    seen.add(nb)
                    queue.append(nb)
    return [node.val for node in queue]
```

```python
    adj = [[] for _ in range(n)]
    for u, v in edges:                 # undirected: add both directions
        adj[u].append(v)
        adj[v].append(u)
    seen = set()

    def dfs(u: int) -> bool:
        if u == destination:
            return True
        seen.add(u)                    # mark before going deeper
        return any(dfs(v) for v in adj[u] if v not in seen)

    return dfs(source)
```

```python
    queue, fresh = deque(), 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == 2:
                queue.append((r, c))   # every rotten orange is a source
            elif grid[r][c] == 1:
                fresh += 1
    minutes = 0
    while queue and fresh:
        for _ in range(len(queue)):    # one full layer = one minute
            r, c = queue.popleft()
            for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
```

```python
    steps = 0

            state = queue.popleft()
            if state == target:

            for i in range(4):
```

@@ uf
what: Union-find keeps items in groups. Every item has a parent pointer, and the root of a chain names the group. def find_redundant_connection(edges: list[list[int]]) -> list[int]:
```python
    parent = list(range(len(edges) + 1))   # each node starts alone

    def find(x: int) -> int:
        while parent[x] != x:
            parent[x] = parent[parent[x]]  # path compression (halving)
            x = parent[x]
        return x

    for u, v in edges:
        ru, rv = find(u), find(v)
        if ru == rv:                       # already joined: this edge closes a cycle
            return [u, v]
        parent[ru] = rv                    # union: link one root to the other
    return []
```

@@ dijkstra
what: Dijkstra finds the shortest distance from one start node to all others when every edge weight is zero or more. Keep a min-heap of (distance, node).
```python
def network_delay_time(times: list[list[int]], n: int, k: int) -> int:
    adj = defaultdict(list)
    for u, v, w in times:
        adj[u].append((v, w))
    dist = {}                          # settled nodes and their final distance
    heap = [(0, k)]
    while heap:
        d, u = heapq.heappop(heap)
        if u in dist:                  # a shorter entry settled u earlier
            continue
        dist[u] = d
        for v, w in adj[u]:
            if v not in dist:
                heapq.heappush(heap, (d + w, v))
    return max(dist.values()) if len(dist) == n else -1
```

@@ quickselect

```python
def find_kth_largest(nums: list[int], k: int) -> int:
    target = len(nums) - k             # index of the answer when sorted
    lo, hi = 0, len(nums) - 1
    while True:
        p = random.randint(lo, hi)     # random pivot avoids bad inputs
        nums[p], nums[hi] = nums[hi], nums[p]
        pivot, store = nums[hi], lo
        for i in range(lo, hi):        # move smaller items to the front
            if nums[i] < pivot:
                nums[i], nums[store] = nums[store], nums[i]
                store += 1
        nums[store], nums[hi] = nums[hi], nums[store]   # pivot to its place
        if store == target:
            return nums[store]
        if store < target:
            lo = store + 1             # answer is on the right
        else:
            hi = store - 1             # answer is on the left
```

@@ dedupe
what: When the input has repeated values, plain backtracking builds the same answer several times. Sort the items so equal values sit next to each other. def subsets_with_dup(nums: list[int]) -> list[list[int]]:
```python
    nums.sort()                        # equal values become neighbours
    result, path = [], []

    def go(start: int) -> None:
        result.append(path[:])         # every path is a valid subset
        for i in range(start, len(nums)):
            if i > start and nums[i] == nums[i - 1]:
                continue               # same value already tried at this level
            path.append(nums[i])
            go(i + 1)
            path.pop()

    go(0)
    return result
```

@@ gridbt
what: To search for a path in a grid where a cell may not be used twice, mark the cell while it is on the current path. Try each of the four neighbours. def exist(board: list[list[str]], word: str) -> bool:
```python
    rows, cols = len(board), len(board[0])

    def dfs(r: int, c: int, i: int) -> bool:
        if i == len(word):
            return True                # all letters matched
        if not (0 <= r < rows and 0 <= c < cols) or board[r][c] != word[i]:
            return False
        ch = board[r][c]
        board[r][c] = "#"              # mark: cell is on the current path
        found = any(dfs(r + dr, c + dc, i + 1)
                    for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)))
        board[r][c] = ch               # unmark: other paths may use it
        return found

    return any(dfs(r, c, 0) for r in range(rows) for c in range(cols))
```

@@ meetmiddle

```python
def min_abs_difference(nums: list[int], goal: int) -> int:
    half = len(nums) // 2

    def sums(part: list[int]) -> list[int]:
        res = [0]                      # the empty subset
        for x in part:
            res += [s + x for s in res]    # each old subset with and without x
        return res

    left = sums(nums[:half])
    right = sorted(sums(nums[half:]))
    best = abs(goal)
    for s in left:
        i = bisect.bisect_left(right, goal - s)   # first right sum >= goal - s
        for j in (i - 1, i):           # the two nearest candidates
            if 0 <= j < len(right):
                best = min(best, abs(s + right[j] - goal))
    return best
```

```python
    placed, result = [], []                    # placed[r] = column of the queen in row r
```

```python
    for i in range(2, n + 1):          # steps 0 and 1 cost nothing to reach
        dp[i] = min(dp[i - 1] + cost[i - 1],     # came from one step below
```

@@ bitmaskdp
what: When n is small (about 20 or less), a set of items can be stored as the bits of one integer: bit i is 1 if item i is used. That integer is a cheap, hashable state for memoisation. The recursion tries each unused item, sets its bit, and caches the result by the mask. There are only 2^n masks, far fewer than n! orders.
signals: n is at most about 15 to 20 ; each item is used exactly once ; count or minimise over all orderings or assignments ; assign people to jobs or numbers to positions ; the answer depends only on which items are used, not their order
code:
```python
from functools import cache

def count_arrangement(n: int) -> int:
    @cache
    def go(pos: int, mask: int) -> int:    # fill position pos; mask = numbers used
        if pos > n:
            return 1                       # every position is filled
        total = 0
        for num in range(1, n + 1):
            if mask >> (num - 1) & 1:      # num already used
                continue
            if num % pos == 0 or pos % num == 0:
                total += go(pos + 1, mask | 1 << (num - 1))
        return total

    return go(1, 0)
```

step: Input n = 2. Call go(1, 0b00): position 1, no numbers used.
step: Try num = 1: 1 % 1 == 0, so it is allowed. Call go(2, 0b01).
step: In go(2, 0b01): num = 1 is used, so skip it. num = 2 works, since 2 % 2 == 0. Call go(3, 0b11), which returns 1.
step: Back in go(1, 0b00), try num = 2: 2 % 1 == 0, so it is allowed. Call go(2, 0b10).
step: In go(2, 0b10): num = 1 works because 2 % 1 == 0, so go(3, 0b11) returns 1. num = 2 is used.
step: The total is 1 + 1 = 2: the arrangements [1, 2] and [2, 1].
bugs: Using a list for the used marks inside the memo key, which cannot be hashed ; Mixing bit positions: number num is bit num - 1, not bit num ; Forgetting parentheses around the shift and the & test, because of operator precedence ; Trying to use this when n is 30 or more; 2^n masks are too many
cost: O(2^n * n) time and O(2^n) extra space, because there are 2^n masks and each tries n numbers; the position is fixed by the count of set bits.

@@ digitdp
what: To count over all numbers from 0 to N, build each number one digit at a time from the left. The state is the position, what you need to track (here, how many ones), and a flag tight. Tight means the digits so far equal the prefix of N, so the next digit is limited. Once a digit is smaller than N's digit, the rest is free, and those states repeat, so memoisation helps.
signals: count numbers up to N with a property of its digits ; N is as large as 10^9 or 10^18 ; how many integers in [1, N] contain a given digit ; sum of digits or digit pattern over a range ; brute force over all numbers is too slow
code:
```python
from functools import cache

def count_digit_one(n: int) -> int:
    digits = list(map(int, str(n)))

    @cache
    def go(i: int, ones: int, tight: bool) -> int:
        if i == len(digits):
            return ones                    # this number is done: add its ones
        limit = digits[i] if tight else 9  # tight: cannot pass N's digit
        total = 0
        for d in range(limit + 1):
            total += go(i + 1, ones + (d == 1), tight and d == limit)
        return total

    return go(0, 0, True)
```

step: Input n = 13, so digits = [1, 3]. Call go(0, 0, True). The first digit may be 0 or 1.
step: d = 0: the number is now below 13 in the first place, so tight becomes False. go(1, 0, False) tries the digits 0 to 9, and only d = 1 adds a one. That gives 1 (the number 01).
step: d = 1: the prefix equals N's first digit, so tight stays True and ones = 1. go(1, 1, True) tries the digits 0 to 3.
step: The numbers 10, 11, 12 and 13 end with 1, 2, 1 and 1 ones. Digits 0, 1, 2, 3 give ones = 1, 2, 1, 1, and the sum is 5.
step: Add the two branches: 1 + 5 = 6. Check by hand: 1, 10, 11 (two), 12, 13 give 1 + 1 + 2 + 1 + 1 = 6.
bugs: Dropping the tight flag, which counts numbers larger than N ; Keeping tight True after choosing a digit below the limit ; Leading zeros: here they are harmless, but for "no repeated digit" tasks they need a started flag ; Putting the count into the memo key without bound, so the cache grows large; track only what you need
cost: O(D * S * 2 * 10) time and O(D * S * 2) extra space for D digits and S counter values, because each state tries up to 10 digits; this is tiny compared with N.

@@ gamedp
what: In a two-player game where both play best, define best(state) as the most the player to move can win by, counting their score minus the opponent's. Each move gives a score now and then the opponent faces a new state, so we subtract the opponent's best from it. Take the max over all moves. Memoise on the state so each one is solved once.
signals: two players take turns and both play optimally ; can the first player win or tie ; maximise your score minus the opponent's score ; pick from either end of an array ; a move leaves a smaller game of the same kind
code:
```python
from functools import cache

def predict_the_winner(nums: list[int]) -> bool:
    @cache
    def best(i: int, j: int) -> int:       # best lead for the player to move on nums[i..j]
        if i == j:
            return nums[i]                 # one item left: take it
        take_left = nums[i] - best(i + 1, j)    # opponent then moves on the rest
        take_right = nums[j] - best(i, j - 1)
        return max(take_left, take_right)

    return best(0, len(nums) - 1) >= 0     # a tie counts as a win for player 1
```
walk: #486 Predict the Winner
step: Input nums = [1, 5, 2]. best(i, j) is the lead of the player to move on the items i to j. We need best(0, 2).
step: Small ranges first. best(1, 2): take 5 and leave [2]: 5 - 2 = 3. Or take 2 and leave [5]: 2 - 5 = -3. So best(1, 2) = 3.
step: best(0, 1): take 1 and leave [5]: 1 - 5 = -4. Or take 5 and leave [1]: 5 - 1 = 4. So best(0, 1) = 4.
step: best(0, 2): take the left 1 and leave [5, 2]: 1 - 3 = -2. Or take the right 2 and leave [1, 5]: 2 - 4 = -2. So best(0, 2) = -2.
step: The lead is -2, which is below 0, so player 1 loses and the answer is False.
bugs: Adding the opponent's best instead of subtracting it ; Returning best(0, n - 1) > 0, which treats a tie as a loss ; Using a greedy rule such as always taking the larger end ; Mixing player scores in the state; the difference alone is enough
cost: O(n^2) time and O(n^2) extra space, because there are n^2 ranges (i, j) and each is solved with two lookups.

@@ rolling
what: To compare many windows of a string, compute the hash of each window from the hash of the previous one. Shift the old hash to make room, add the new character, and remove the oldest one. That costs O(1) per window instead of O(window length). For DNA, 2 bits per letter give an exact number, so equal hashes mean equal text. With a modulus, equal hashes still need a text check.
signals: repeated substrings of a fixed length ; find a pattern inside a long text ; compare all windows of length k ; substring hashes in a sliding window ; longest repeated substring with binary search
code:
```python
def find_repeated_dna_sequences(s: str) -> list[str]:
    size = 10
    code = {"A": 0, "C": 1, "G": 2, "T": 3}   # 2 bits per letter
    mask = (1 << (2 * size)) - 1              # keeps the last 10 letters
    seen, repeated = set(), set()
    h = 0
    for i, ch in enumerate(s):
        h = ((h << 2) | code[ch]) & mask      # push new letter, drop the oldest
        if i >= size - 1:                     # a full window is ready
            if h in seen:
                repeated.add(s[i - size + 1:i + 1])
            seen.add(h)
    return list(repeated)
```

step: After the first 9 letters the window is not full yet, so nothing is stored.
step: At i = 9 the tenth T arrives: h = 1048575 (twenty 1 bits). The window is full and h is not in seen, so add it.
step: At i = 10 the eleventh T arrives: shift left, add 3, then the mask drops the oldest letter. h is 1048575 again.
step: 1048575 is already in seen, so add the window s[1:11] = "TTTTTTTTTT" to the answer.
step: Return ["TTTTTTTTTT"]. Every window cost O(1) work, not O(10).
bugs: Recomputing each window's hash from scratch, which is O(n * k) ; Forgetting to mask, so old letters stay in the hash and it grows without bound ; Using a modular hash and trusting equal hashes without comparing the text ; Reporting a window each time it repeats; a set avoids duplicates in the answer ; Subtracting the old letter with the wrong power of the base
cost: O(n) time and O(n) extra space, because each window costs O(1) and the hashes of up to n windows are stored.

@@ zfunc
what: The Z-function of a string gives, for each position i, the length of the longest match between the string and its own start. Keep the rightmost match box [l, r) found so far. A new position inside the box can copy a value from the matching spot near the start, so it often needs no new comparisons. Each character is compared fresh only when the box grows, so the total is O(n).
signals: longest common prefix of the string and each of its suffixes ; score of each suffix against the whole string ; find a pattern by building pattern + separator + text ; prefix that is also a suffix or a repeat period ; every position is compared with the start of the same string
code:
```python
def sum_scores(s: str) -> int:
    n = len(s)
    z = [0] * n
    z[0] = n                           # the whole string matches itself
    l = r = 0                          # rightmost match box is s[l:r]
    for i in range(1, n):
        if i < r:                      # inside the box: reuse an earlier value
            z[i] = min(r - i, z[i - l])
        while i + z[i] < n and s[z[i]] == s[i + z[i]]:
            z[i] += 1                  # extend by real comparison
        if i + z[i] > r:
            l, r = i, i + z[i]         # the box moved right
    return sum(z)
```
walk: #2223 Sum of Scores of Built Strings
step: Input s = "babab", n = 5. Set z[0] = 5 and the box l = r = 0. The score of each suffix is its z value.
step: i = 1: outside the box. Compare s[0] = b with s[1] = a: no match, so z[1] = 0.
step: i = 2: outside the box. b = b, a = a, b = b match, so z[2] = 3 and the box becomes l = 2, r = 5.
step: i = 3: inside the box. z = min(5 - 3, z[1]) = min(2, 0) = 0. Then b versus a fails, so z[3] = 0.
step: i = 4: inside the box. z = min(5 - 4, z[2]) = min(1, 3) = 1. The end of the string is reached, so z[4] = 1.

bugs: Forgetting that z[0] is the whole length n, which this problem counts ; Copying z[i - l] without capping it by r - i ; Not updating the box after extending past r ; Using a plain nested loop for each suffix, which is O(n²)
cost: O(n) time and O(n) extra space, because the right edge r only moves forward and each character is matched fresh at most once.
