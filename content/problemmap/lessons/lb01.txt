what: The Boyer-Moore vote keeps one candidate and a counter. A matching value adds one to the counter, a different value removes one, and at zero the next value becomes the candidate. Each removal cancels two different items, so a value that is more than half of the array cannot be cancelled away. It finds the majority in O(1) space.
signals: appears more than n / 2 times ; majority element ; guaranteed that a majority exists ; O(1) extra space needed ; more than n / 3 times (use two candidates)
code:
```python
def majority_element(nums: list[int]) -> int:
    cand, cnt = 0, 0
    for x in nums:
        if cnt == 0:
            cand = x                 # pick a new candidate
        cnt += 1 if x == cand else -1
    return cand                      # valid when a majority is guaranteed
```

@@ prefixsum
what: A prefix sum array stores the running total up to each position. The sum of any range from l to r is then prefix[r + 1] minus prefix[l], which takes O(1) time. You pay O(n) once to build the table, and every later range question is a single subtraction.
signals: sum of a subarray or range ; many queries on the same array ; running total or cumulative sum ; subarray with sum equal to k ; count of items up to index i
code:
```python
def running_sum(nums: list[int]) -> list[int]:
    out, total = [], 0
    for x in nums:
        total += x
        out.append(total)        # out[i] = nums[0] + ... + nums[i]
    return out

def range_sum(prefix: list[int], l: int, r: int) -> int:
    before = prefix[l - 1] if l > 0 else 0
    return prefix[r] - before    # sum of nums[l..r]
```

@@ fixedwin
what: A fixed window is a block of k neighbouring items that slides one step at a time. When it moves, one item enters on the right and one item leaves on the left, so you update the total with two operations instead of adding k items again. Each window costs O(1), and the whole scan costs O(n).
signals: subarray of size k ; every window of length k ; maximum or average of k consecutive items ; substring of fixed length ; k is given in the input
code:
```python
def find_max_average(nums: list[int], k: int) -> float:
    window = sum(nums[:k])               # first window
    best = window
    for i in range(k, len(nums)):
        window += nums[i] - nums[i - k]  # add the new item, drop the old one
        best = max(best, window)
    return best / k
```

bugs: Dropping nums[i - k + 1] instead of nums[i - k] ; Recomputing sum(nums[i - k:i]) for each window, which is O(n * k) ; Starting best at 0, which is wrong when all sums are negative ; Dividing by k inside the loop and getting rounding drift

@@ merge2
what: To merge two sorted lists, keep one pointer in each and always take the smaller of the two items they point to. Because both lists are already sorted, the smaller head is the next item of the merged result. If one list has spare room at its end, fill from the back so you never overwrite an item you still need.
signals: two sorted arrays or lists ; merge into one sorted array ; merge in place with spare space at the end ; union or intersection of sorted lists ; combine sorted pieces (merge sort step)
code:
```python
def merge(nums1: list[int], m: int, nums2: list[int], n: int) -> None:
    i, j, k = m - 1, n - 1, m + n - 1    # three pointers, all moving left
    while j >= 0:                        # nums1 items left are already in place
        if i >= 0 and nums1[i] > nums2[j]:
            nums1[k] = nums1[i]
            i -= 1
        else:
            nums1[k] = nums2[j]
            j -= 1
        k -= 1
```

@@ subseq-match

@@ twoptr
what: Place one pointer at each end of the array and move them toward each other. At each step you compare or combine the two items and decide which pointer to move. When the data has an order or a symmetry, the choice is clear, so you cover all pairs in one pass of O(n).
signals: palindrome ; sorted array and a pair with a target sum ; compare the first and the last item ; reverse in place ; container or area between two ends

```python
def is_palindrome(s: str) -> bool:
    l, r = 0, len(s) - 1
    while l < r:
        while l < r and not s[l].isalnum():   # skip punctuation and spaces
            l += 1
        while l < r and not s[r].isalnum():
            r -= 1
        if s[l].lower() != s[r].lower():
            return False
        l += 1
        r -= 1
    return True
```

@@ dummyhead

```python
        if cur.next.val == val:
            cur.next = cur.next.next     # unlink the next node

    return dummy.next
```

@@ fastslow
what: Use two pointers that move at different speeds along a linked list: slow moves one node per step and fast moves two. If the list has a cycle, fast laps slow and they meet inside the loop. If there is no cycle, fast reaches the end. When fast is at the end, slow is at the middle. No set of visited nodes is needed.
signals: detect a cycle in a linked list ; find the middle node ; O(1) memory, no hash set ; the start of a loop ; k-th node from the end (with a gap)
code:
```python
def has_cycle(head: "ListNode | None") -> bool:
    slow = fast = head
    while fast and fast.next:        # fast reaches the end if there is no cycle
        slow = slow.next             # one step
        fast = fast.next.next        # two steps
        if slow is fast:             # same node, not just the same value
            return True
    return False
```

@@ llreverse

```python
def reverse_list(head: "ListNode | None") -> "ListNode | None":

        cur.next = prev      # turn the link around
        prev = cur           # step forward
        cur = nxt
    return prev              # prev is the new head
```

@@ queuebasic
what: A queue handles items in the order they arrive: add at the back and remove from the front. In Python use collections.deque, whose popleft is O(1) (a list pop(0) is O(n)). A queue fits problems where old items expire and you keep only the recent ones.

```python
from collections import deque

class RecentCounter:
    def __init__(self):
        self.q: deque[int] = deque()

    def ping(self, t: int) -> int:
        self.q.append(t)                      # new request goes to the back
        while self.q[0] < t - 3000:           # too old: remove from the front
            self.q.popleft()
        return len(self.q)
```

```python
def is_valid(s: str) -> bool:
```
