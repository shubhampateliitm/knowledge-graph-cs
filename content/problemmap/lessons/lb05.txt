@@ trie
what: A trie stores words one letter at a time along paths in a tree, so words with the same prefix share the same path. To find a word or a prefix you walk one node per letter, so the cost depends on the word length, not on how many words are stored. A flag on a node marks where a whole word ends.
signals: "prefix" or "starts with" queries on many words ; autocomplete or dictionary lookup ; "implement insert, search and startsWith" ; match many words against a board or text letter by letter ; longest common prefix of a group of words
code:
```python
class Trie:
    def __init__(self):
        self.root: dict = {}              # each node maps a letter to a child node

    def insert(self, word: str) -> None:
        node = self.root
        for ch in word:
            node = node.setdefault(ch, {})   # create the child if it is missing
        node["$"] = True                  # mark: a word ends here

    def _walk(self, s: str):
        node = self.root
        for ch in s:
            if ch not in node:
                return None
            node = node[ch]
        return node

    def search(self, word: str) -> bool:
        node = self._walk(word)
        return node is not None and "$" in node

    def starts_with(self, prefix: str) -> bool:
        return self._walk(prefix) is not None
```

step: search("app") walks a, p, p fine, but the node has no end mark yet, so it returns False.

@@ fastpow
what: To compute x to the power n, write n in binary. Square the base on every step and multiply it into the result only when the current bit of n is 1. This needs about log2(n) multiplications instead of n.
signals: "compute x^n" with a huge n ; "pow(x, n)" or "modular power" ; the exponent is up to 10^9 or more ; repeat the same step n times where n is huge ; raise a matrix to a large power
code:
```python
def my_pow(x: float, n: int) -> float:
    if n < 0:                  # x^-n is (1/x)^n
        x, n = 1 / x, -n
    result = 1.0
    while n:
        if n & 1:              # this bit of n is 1: use the current base
            result *= x
        x *= x                 # base becomes x^2, x^4, x^8, ...
        n >>= 1                # move to the next bit
    return result
```

step: Input x = 2, n = 10. In binary 10 is 1010. Start with result = 1.
step: n = 10, the last bit is 0, so skip. Square the base: x = 4. Shift: n = 5.
step: n = 5, the last bit is 1, so result = 1 * 4 = 4. Then x = 16, n = 2.
step: n = 2, the last bit is 0, so skip. Then x = 256, n = 1.
step: n = 1, the last bit is 1, so result = 4 * 256 = 1024. Then x = 65536, n = 0.
step: The loop ends and the answer is 1024, which is 2^2 * 2^8 = 2^10. Only 4 rounds were needed, not 10.

@@ inclexcl
what: To count items in a union of sets, add the sizes of single sets, subtract the sizes of every pair overlap, add back every triple overlap, and so on. This fixes the double counting that a plain sum makes. For "divisible by a, b or c", each overlap is the multiples of the lcm.
signals: "divisible by a, b or c" ; count numbers that satisfy at least one of several conditions ; the answer is too big to list one by one ; "nth number" divisible by one of a few values ; count items that avoid all of several bad properties
code:
```python
from math import gcd

def nth_ugly_number(n: int, a: int, b: int, c: int) -> int:
    def lcm(x: int, y: int) -> int:
        return x * y // gcd(x, y)
    ab, ac, bc = lcm(a, b), lcm(a, c), lcm(b, c)
    abc = lcm(ab, c)

    def count(m: int) -> int:       # how many of 1..m divide by a, b or c
        return (m // a + m // b + m // c
                - m // ab - m // ac - m // bc
                + m // abc)

    lo, hi = 1, 2 * 10**9
    while lo < hi:                  # smallest m with count(m) >= n
        mid = (lo + hi) // 2
        if count(mid) >= n:
            hi = mid
        else:
            lo = mid + 1
    return lo
```

@@ nim

```python
def brute(n: int) -> list[bool]:
    # win[i] is True if the player to move can force a win with i stones
    win = [False] * (n + 1)          # 0 stones: the player to move has lost
    for i in range(1, n + 1):
        win[i] = any(not win[i - k] for k in (1, 2, 3) if k <= i)
    return win

    # brute shows the losing positions are 0, 4, 8, 12, ...
    return n % 4 != 0
```

@@ permrank
what: There are (n-1)! permutations that start with each fixed first item. So dividing the zero-based rank k by (n-1)! tells you which remaining item comes first. The remainder is the rank inside that block, and you repeat with the next smaller factorial. This builds the answer in n steps instead of listing permutations.
signals: "k-th permutation" ; find the permutation at a given rank without listing all ; n up to 9 or more with k up to n! ; "the rank of this permutation" ; lexicographic order of arrangements
code:
```python
from math import factorial

def get_permutation(n: int, k: int) -> str:
    items = [str(i) for i in range(1, n + 1)]   # sorted, still unused
    k -= 1                                      # make the rank 0-based
    out = []
    for size in range(n, 0, -1):
        block = factorial(size - 1)             # permutations per first item
        idx, k = divmod(k, block)
        out.append(items.pop(idx))              # take that item out
    return "".join(out)
```

@@ sieve
what: Start with every number marked prime. For each prime p, cross out its multiples starting at p*p, because smaller multiples were already crossed out by smaller primes. What is left uncrossed is prime. This costs about n log log n steps, far less than testing each number alone.
signals: "count primes less than n" ; list all primes up to a limit ; you need many primality answers for the same range ; n up to a few million ; smallest prime factor for every number
code:
```python
def count_primes(n: int) -> int:
    if n < 3:
        return 0
    is_prime = [True] * n
    is_prime[0] = is_prime[1] = False
    p = 2
    while p * p < n:                    # larger p have no new multiples to cross
        if is_prime[p]:
            for m in range(p * p, n, p):
                is_prime[m] = False
        p += 1
    return sum(is_prime)
```

step: Input n = 10. We count primes below 10. Make a list for 0 to 9, all True, then mark 0 and 1 as False.

step: p = 3 and 3 * 3 = 9 < 10. 3 is prime, so cross out 9.
step: p = 4 gives 16, which is not below 10, so the loop stops.

bugs: Starting the inner loop at 2*p instead of p*p, which is correct but does extra work ; Counting n itself, when the problem asks for primes strictly less than n ; Forgetting to mark 0 and 1 as not prime ; Running p up to n instead of the square root
cost: O(n log log n) time and O(n) extra space for the flag list, because each prime p crosses out about n/p numbers.

@@ slopehash
what: Two points lie on the same line through a base point when their direction (dy, dx) is equal after reduction. Divide both parts by their gcd and fix the sign, so every equal direction gets the same key. A hash map then counts how many points share each direction. This avoids float division and its rounding errors.
signals: "maximum points on a line" ; count points that are collinear ; group pairs by slope or direction ; equal ratios must be treated as equal ; vertical lines must be handled too
code:
```python
from math import gcd

def max_points(points: list[list[int]]) -> int:
    n = len(points)
    if n <= 2:
        return n
    best = 0
    for i in range(n):
        x1, y1 = points[i]
        slopes: dict[tuple[int, int], int] = {}
        for j in range(i + 1, n):
            dx, dy = points[j][0] - x1, points[j][1] - y1
            g = gcd(dx, dy)                   # gcd is never negative
            dx, dy = dx // g, dy // g
            if dx < 0 or (dx == 0 and dy < 0):
                dx, dy = -dx, -dy             # one sign for each direction
            slopes[(dy, dx)] = slopes.get((dy, dx), 0) + 1
        if slopes:
            best = max(best, max(slopes.values()) + 1)   # +1 for the base point
    return best
```

@@ maskenum
what: A set of n items can be written as an n-bit number, where bit i says whether item i is chosen. Looping mask from 0 to 2^n - 1 visits every subset exactly once. It is simple and has no recursion, and it works when n is small, up to about 20.
signals: n is at most 15 to 20 ; "count subsets" or "all subsets" with a property ; try every combination of choose or skip ; "maximum bitwise OR" over subsets ; the constraint is small enough for 2^n work
code:
```python
def count_max_or_subsets(nums: list[int]) -> int:
    n = len(nums)
    best, count = 0, 0
    for mask in range(1, 1 << n):         # skip 0, the empty subset
        cur = 0
        for i in range(n):
            if mask >> i & 1:             # item i is in this subset
                cur |= nums[i]
        if cur > best:
            best, count = cur, 1
        elif cur == best:
            count += 1
    return count
```

@@ perbit

```python
def single_number(nums: list[int]) -> int:

    for bit in range(32):
        total = sum((x >> bit) & 1 for x in nums)   # how many have this bit set
        if total % 3:                               # the single number has it
```

@@ prefixxor
what: Let prefix[i] be the XOR of the first i items. Because x ^ x = 0, the XOR of items l to r is prefix[r+1] ^ prefix[l]. The shared part cancels. This is the same trick as prefix sums, with XOR in place of plus and minus.
signals: XOR of a subarray ; many range XOR queries ; "subarray with XOR equal to k" ; count pairs of prefixes with a given XOR ; XOR plays the role of sum in a range problem

```python
def xor_queries(arr: list[int], queries: list[list[int]]) -> list[int]:
    prefix = [0]                          # prefix[i] = XOR of arr[0..i-1]
    for x in arr:
        prefix.append(prefix[-1] ^ x)
    # XOR of arr[l..r]: the shared start cancels out
    return [prefix[r + 1] ^ prefix[l] for l, r in queries]
```

@@ xorsplit
what: If a and b are two different numbers, a ^ b has at least one bit set, and a and b differ at that bit. Use that bit to split all numbers into two groups. Each group holds one unique number plus pairs, so XOR of a group cancels the pairs and leaves the unique number.
signals: exactly two numbers appear once, all others twice ; "find the two single numbers" ; XOR of everything gives a ^ b, not one answer ; need two answers in O(1) space ; split the data by one bit

```python
def single_number(nums: list[int]) -> list[int]:
    xor_all = 0
    for x in nums:
        xor_all ^= x                  # pairs cancel, leaving a ^ b
    low = xor_all & -xor_all          # lowest set bit: a and b differ here
    a = 0
    for x in nums:
        if x & low:                   # group with this bit set
            a ^= x
    return [a, xor_all ^ a]
```

@@ fenwick
what: A Fenwick tree stores in slot i the sum of a block of items that ends at i. The block length is the lowest set bit of i. A prefix sum adds a few blocks by stepping i -= i & -i. An update touches the blocks that cover the item by stepping i += i & -i. Both take O(log n).
signals: array with point updates and range sum queries ; "update and query many times" ; prefix sums that change over time ; count smaller items to the right while inserting ; need a short code that is faster than recomputing sums
code:
```python
class NumArray:
    def __init__(self, nums: list[int]):
        self.n = len(nums)
        self.nums = [0] * self.n
        self.tree = [0] * (self.n + 1)       # 1-based Fenwick array
        for i, v in enumerate(nums):
            self.update(i, v)

    def update(self, index: int, val: int) -> None:
        delta = val - self.nums[index]
        self.nums[index] = val
        i = index + 1
        while i <= self.n:
            self.tree[i] += delta
            i += i & -i                      # go to the next block covering i

    def _prefix(self, i: int) -> int:        # sum of the first i items
        total = 0
        while i > 0:
            total += self.tree[i]
            i -= i & -i                      # drop the lowest set bit
        return total

    def sum_range(self, left: int, right: int) -> int:
        return self._prefix(right + 1) - self._prefix(left)
```

@@ randomset
what: Keep the values in an array for fast random picks, and keep a map from each value to its array index. To delete in O(1), move the last array item into the deleted slot and pop the end. The map is updated for the moved item. Order does not matter, so the swap is safe.

```python
import random

class RandomizedSet:
    def __init__(self):
        self.vals: list[int] = []
        self.pos: dict[int, int] = {}          # value -> index in vals

    def insert(self, val: int) -> bool:
        if val in self.pos:
            return False
        self.pos[val] = len(self.vals)
        self.vals.append(val)
        return True

    def remove(self, val: int) -> bool:
        if val not in self.pos:
            return False
        i, last = self.pos[val], self.vals[-1]
        self.vals[i] = last                    # move the last item into the hole
        self.pos[last] = i
        self.vals.pop()
        del self.pos[val]                      # after the update, so val == last works
        return True

    def get_random(self) -> int:
        return random.choice(self.vals)
```

@@ segtree
what: A segment tree stores in each node a summary, such as the sum, of one range of the array. The root covers everything, and the two children cover the left and right halves. A point update fixes the nodes on one path to the root. A range query combines O(log n) nodes. This version uses the bottom-up array layout with leaves at n to 2n-1.
signals: range query with point updates ; "sum, min or max of a range" that changes over time ; update and query are both called many times ; the summary must combine in any order, like sum, min, max, gcd ; later problems add lazy range updates
code:
```python
class NumArray:
    def __init__(self, nums: list[int]):
        self.n = len(nums)
        self.tree = [0] * (2 * self.n)
        self.tree[self.n:] = nums                    # leaves
        for i in range(self.n - 1, 0, -1):           # parents from the bottom
            self.tree[i] = self.tree[2 * i] + self.tree[2 * i + 1]

    def update(self, index: int, val: int) -> None:
        i = index + self.n
        self.tree[i] = val
        while i > 1:                                 # fix the path to the root
            i //= 2
            self.tree[i] = self.tree[2 * i] + self.tree[2 * i + 1]

    def sum_range(self, left: int, right: int) -> int:
        lo, hi = left + self.n, right + self.n + 1   # half-open [lo, hi)
        total = 0
        while lo < hi:
            if lo & 1:                               # lo is a right child: take it
                total += self.tree[lo]
                lo += 1
            if hi & 1:                               # hi - 1 is a right child: take it
                hi -= 1
                total += self.tree[hi]
            lo //= 2
            hi //= 2
        return total
```

@@ skiplist
what: A skip list is a sorted linked list with extra "express" lanes above it. Each new node gets a random height. On a high lane the search jumps over many nodes, then drops down a lane when the next jump is too far. With random heights, a search takes O(log n) steps on average, without any tree balancing.
signals: "Design a skiplist" ; sorted data with insert, delete and search, and no built-in tree allowed ; "O(log n) expected" using random levels ; duplicates are allowed in the structure ; a linked list that must be searched faster than one step at a time
code:
```python
import random

class Node:
    def __init__(self, val: int, level: int):
        self.val = val
        self.next: list = [None] * level      # one forward link per lane

class Skiplist:
    MAX = 16

    def __init__(self):
        self.head = Node(-1, self.MAX)

    def _find_prev(self, num: int) -> list:
        prev, cur = [self.head] * self.MAX, self.head
        for lv in range(self.MAX - 1, -1, -1):          # top lane first
            while cur.next[lv] and cur.next[lv].val < num:
                cur = cur.next[lv]                      # jump ahead on this lane
            prev[lv] = cur                              # last node below num here
        return prev

    def search(self, target: int) -> bool:
        node = self._find_prev(target)[0].next[0]
        return node is not None and node.val == target

    def add(self, num: int) -> None:
        prev = self._find_prev(num)
        level = 1
        while level < self.MAX and random.random() < 0.5:   # coin flips
            level += 1
        node = Node(num, level)
        for lv in range(level):
            node.next[lv] = prev[lv].next[lv]
            prev[lv].next[lv] = node

    def erase(self, num: int) -> bool:
        prev = self._find_prev(num)
        node = prev[0].next[0]
        if node is None or node.val != num:
            return False
        for lv in range(len(node.next)):
            if prev[lv].next[lv] is node:
                prev[lv].next[lv] = node.next[lv]
        return True
```

@@ cyclesim

```python
def prison_after_n_days(cells: list[int], n: int) -> list[int]:
    def step(c: tuple) -> tuple:
        # ends have only one neighbour, so they become empty
        return (0,) + tuple(int(c[i - 1] == c[i + 1]) for i in range(1, 7)) + (0,)

    seen: dict[tuple, int] = {}          # state -> days left when first seen
    state = tuple(cells)
    while n > 0:
        if state in seen:
            n %= seen[state] - n         # skip whole cycles
            if n == 0:
                break
        seen[state] = n
        state = step(state)
        n -= 1
    return list(state)
```

@@ js-throttle
what: Debounce waits for a quiet period: every new call cancels the timer of the last one, so only the last call in a burst runs. Throttle limits the rate: a call runs only if enough time has passed since the last run, and other calls are dropped. Both use a timer or a clock and one saved variable.
signals: "debounce" or "throttle" ; calls must be delayed or dropped ; "run only the last call after t milliseconds of quiet" ; limit how often a function runs ; typing, scrolling or resize events
code:
```python
import threading
import time

def debounce(fn, t: float):                   # t is in seconds
    timer = None
    def debounced(*args):
        nonlocal timer
        if timer is not None:
            timer.cancel()                    # drop the earlier pending call
        timer = threading.Timer(t, fn, args)  # run only if no new call comes
        timer.start()
    return debounced

def throttle(fn, t: float):
    last = None
    def throttled(*args):
        nonlocal last
        now = time.monotonic()
        if last is None or now - last >= t:   # enough time has passed
            last = now
            return fn(*args)
    return throttled
```

@@ bucket
what: Put the numbers into buckets of equal width. By the pigeonhole principle, if the width is chosen well, the largest gap cannot be inside one bucket; it must be between the max of one bucket and the min of the next. So keep only the min and max of each bucket. This gives a linear time answer without sorting.
signals: "maximum gap" between sorted neighbours but the array is not sorted ; you need O(n) time and may not sort ; the values lie in a known range ; "closest pair" or "at least k values within a range" ; counting by value ranges rather than by exact values
code:
```python
def maximum_gap(nums: list[int]) -> int:
    n = len(nums)
    if n < 2:
        return 0
    lo, hi = min(nums), max(nums)
    if lo == hi:
        return 0
    size = max(1, (hi - lo) // (n - 1))        # width so the gap cannot hide inside
    count = (hi - lo) // size + 1
    mins: list = [None] * count
    maxs: list = [None] * count
    for x in nums:
        b = (x - lo) // size
        mins[b] = x if mins[b] is None else min(mins[b], x)
        maxs[b] = x if maxs[b] is None else max(maxs[b], x)
    best, prev_max = 0, lo
    for b in range(count):
        if mins[b] is None:                    # empty bucket
            continue
        best = max(best, mins[b] - prev_max)   # gap to the previous used bucket
        prev_max = maxs[b]
    return best
```

@@ inversions
what: During merge sort, both halves are already sorted when you merge them. For each item in the left half, count how many items in the right half form a pair with it, by moving a pointer forward in the right half. The pointer never goes back, so counting is linear per merge. This turns an O(n^2) pair count into O(n log n).
signals: "count pairs i < j with nums[i] > nums[j]" ; "reverse pairs" or "inversions" ; count of smaller elements after self ; pair condition compares two values, and the order of indexes matters ; n up to 5 * 10^4 or more, so O(n^2) is too slow
code:
```python
def reverse_pairs(nums: list[int]) -> int:
    def sort(a: list[int]):
        if len(a) <= 1:
            return a, 0
        mid = len(a) // 2
        left, cl = sort(a[:mid])
        right, cr = sort(a[mid:])
        count = cl + cr
        j = 0
        for x in left:                       # left and right are both sorted
            while j < len(right) and x > 2 * right[j]:
                j += 1                       # right[0..j-1] all pair with x
            count += j
        merged, i, k = [], 0, 0              # standard merge of two sorted runs
        while i < len(left) and k < len(right):
            if left[i] <= right[k]: merged.append(left[i]); i += 1
            else: merged.append(right[k]); k += 1
        return merged + left[i:] + right[k:], count

    return sort(nums)[1]
```

```python
def num_subarrays_with_sum(nums: list[int], goal: int) -> int:
    def at_most(k: int) -> int:             # subarrays with sum <= k
        if k < 0:
            return 0
        left = total = count = 0
        for right, x in enumerate(nums):
            total += x
            while total > k:                # shrink until the sum fits
                total -= nums[left]
                left += 1
            count += right - left + 1       # every start from left..right works
        return count

    return at_most(goal) - at_most(goal - 1)
```

```python
def three_sum(nums: list[int]) -> list[list[int]]:
    nums.sort()
    result = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue                          # same first item as before
        lo, hi = i + 1, len(nums) - 1
        while lo < hi:
            s = nums[i] + nums[lo] + nums[hi]
            if s < 0:
                lo += 1
            elif s > 0:
                hi -= 1
            else:
                result.append([nums[i], nums[lo], nums[hi]])

                hi -= 1
```

@@ minwin
what: Grow the right end until the window holds everything needed. Then shrink from the left while the window still holds everything, and record the shortest one. Keep a count of what is still missing, so each step is O(1). Each pointer moves forward only, so it is linear.
signals: "minimum window" or "shortest substring" that contains all of something ; cover all required characters ; smallest subarray with sum at least target ; window must satisfy a "contains all" condition ; need counts, not just presence
code:
```python
from collections import Counter

def min_window(s: str, t: str) -> str:
    need = Counter(t)               # need[c] > 0: still needed; < 0: extra copies
    missing = len(t)                # how many needed characters are not yet covered
    left = 0
    best_start, best_len = 0, float("inf")
    for right, ch in enumerate(s):
        if need[ch] > 0:
            missing -= 1
        need[ch] -= 1
        if missing == 0:            # the window is valid
            while need[s[left]] < 0:        # drop extra characters on the left
                need[s[left]] += 1
                left += 1
            if right - left + 1 < best_len:
                best_start, best_len = left, right - left + 1
            need[s[left]] += 1      # drop one needed char to search further
            missing += 1
            left += 1
    return "" if best_len == float("inf") else s[best_start:best_start + best_len]
```

cost: O(n + m) time and O(m) extra space, because each pointer moves at most n steps and the count map holds at most the distinct characters of t.

@@ calc
what: Read the expression left to right and remember the last operator seen. When a new operator arrives, apply the last one to the number just read. Plus and minus push the number (with sign) on a stack, but times and divide act at once on the top of the stack. At the end, sum the stack. For parentheses, save the state on a stack at '(' and restore it at ')'.
signals: "evaluate the expression" given as a string ; operators + - * / with precedence ; parentheses may appear ; "implement a basic calculator" ; numbers have many digits and spaces may appear
code:
```python
def calculate(s: str) -> int:
    stack: list[int] = []
    num = 0
    op = "+"                       # the operator before the current number
    for i, ch in enumerate(s):
        if ch.isdigit():
            num = num * 10 + int(ch)
        if ch in "+-*/" or i == len(s) - 1:
            if op == "+":
                stack.append(num)
            elif op == "-":
                stack.append(-num)
            elif op == "*":
                stack.append(stack.pop() * num)      # binds tighter: act now
            else:
                stack.append(int(stack.pop() / num)) # truncate toward zero
            op = ch
            num = 0
    return sum(stack)
```

step: Input s = "3+2*2". Start with op = "+", num = 0, stack = [].
step: Read 3, so num = 3. Then "+" arrives: apply the old op "+", push 3. Now op = "+" and num = 0. stack = [3].
step: Read 2, so num = 2. Then "*" arrives: apply the old op "+", push 2. Now op = "*". stack = [3, 2].

bugs: Using integer floor division with // on a negative result, when the rule is to truncate toward zero ; Forgetting to flush the last number at the end of the string ; Applying + and - at once, which breaks precedence ; Not resetting num after an operator ; Treating spaces as numbers or operators
cost: O(n) time and O(n) extra space, because each character is read once and the stack holds at most one number for each + or - term.

@@ greedy-stack
what: To get the smallest sequence after removing k items, a larger earlier digit is worse than a smaller later one. Keep a stack. When a new digit is smaller than the top, pop the top while you still may remove items. If removals are left at the end, cut them from the back, where the stack is largest.
signals: "remove k digits to make the smallest number" ; lexicographically smallest subsequence ; keep a result in order and delete items ; "remove duplicate letters" or "smallest subsequence of length k" ; a larger earlier item can be replaced by a smaller later one
code:
```python
def remove_kdigits(num: str, k: int) -> str:
    stack: list[str] = []
    for d in num:
        while k and stack and stack[-1] > d:   # a bigger digit earlier is worse
            stack.pop()
            k -= 1
        stack.append(d)
    if k:                                      # still to remove: cut from the end
        stack = stack[:-k]
    return "".join(stack).lstrip("0") or "0"
```

cost: O(n) time and O(n) extra space, because each digit is pushed once and popped at most once.

@@ histogram
what: Keep a stack of bars with rising heights. When a new bar is shorter than the top, the top bar cannot extend further right. The bar below it on the stack is its nearest shorter bar on the left. So its widest rectangle is known the moment it is popped. A sentinel bar of height 0 at the end pops all the rest.
signals: "largest rectangle in a histogram" ; maximal rectangle in a binary matrix ; for each bar, find how far it can extend left and right ; nearest smaller value on both sides ; area equals height times a width found by neighbours
code:
```python
def largest_rectangle_area(heights: list[int]) -> int:
    hs = heights + [0]                 # sentinel: pops everything at the end
    stack: list[int] = []              # indexes with increasing heights
    best = 0
    for i, h in enumerate(hs):
        while stack and hs[stack[-1]] >= h:
            height = hs[stack.pop()]
            left = stack[-1] if stack else -1       # nearest shorter bar on the left
            best = max(best, height * (i - left - 1))
        stack.append(i)
    return best
```

cost: O(n) time and O(n) extra space, because each bar is pushed once and popped once.

@@ mono-deque
what: To get the maximum of every window of size k, keep a deque of indexes whose values decrease from front to back. A new item removes all smaller items from the back, since they can never be the max while the new item is in the window. The front is the max of the window, and it is dropped when it leaves the window.
signals: "sliding window maximum" or minimum ; max or min of every window of size k ; a window that moves one step at a time ; DP with a "best of the last k values" ; O(n log k) with a heap is too slow
code:
```python
from collections import deque

def max_sliding_window(nums: list[int], k: int) -> list[int]:
    dq: deque[int] = deque()           # indexes; their values go down front to back
    out: list[int] = []
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x:
            dq.pop()                   # smaller items can never win again
        dq.append(i)
        if dq[0] <= i - k:             # the front left the window
            dq.popleft()
        if i >= k - 1:                 # the first full window is complete
            out.append(nums[dq[0]])
    return out
```
