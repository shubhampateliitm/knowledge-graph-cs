@@ hashset
what: A hash set stores values so that "have I seen this before?" takes constant time on average. Each value is hashed to a bucket, so a lookup checks one small bucket instead of the whole list. You trade O(n) extra memory for skipping a second loop over the data.
signals: "contains duplicate" or "appears twice" ; "first repeated" or "first unique" ; "is x in the list?" asked many times ; you need to remove repeats or count distinct values
code:
```python
def contains_duplicate(nums: list[int]) -> bool:
    seen = set()
    for x in nums:
        if x in seen:      # O(1) on average: one bucket is checked
            return True
        seen.add(x)
    return False
```
walk: #217 Contains Duplicate
step: Input nums = [1, 2, 3, 1]. Start with an empty set: seen = {}.
step: x = 1 is not in seen, so add it: seen = {1}.
step: x = 2 and x = 3 are new too: seen = {1, 2, 3}.
step: x = 1 is already in seen, so return True at once; the rest of the array is never read.
step: For [1, 2, 3, 4] every value is new, the loop ends, and the answer is False.
bugs: Sorting first works but costs O(n log n) and changes the input order ; Using a list instead of a set makes each "in" check O(n), so the whole loop becomes O(n²) ; Adding x before checking it, so every value looks like a duplicate of itself
cost: O(n) time on average and O(n) extra space for the set; O(n²) time in the rare worst case when many values share one bucket.
