@@ rollbs
what: A rolling hash turns every substring of length L into a number, and the next number comes from the last one in O(1). If a repeated substring of length L exists, then one of length L-1 also exists, so "is there a repeat of length L?" is a yes-then-no pattern. That lets you binary search the length L instead of trying every length, and test each length in one pass with a set of hashes.
signals: longest repeated or duplicate substring ; longest common substring of two strings ; "does a substring of length k exist?" is easy to test ; length up to 10^5, so O(n²) compare fails ; answer length can be searched because shorter lengths always work
code:
```python
def longest_dup_substring(s: str) -> str:
    n, MOD, B = len(s), (1 << 61) - 1, 131

    def find(L: int) -> int:           # start of a repeat of length L, or -1
        h = 0
        for ch in s[:L]:
            h = (h * B + ord(ch)) % MOD
        pw = pow(B, L, MOD)            # weight of the char that leaves the window
        seen = {h: 0}
        for i in range(1, n - L + 1):
            h = (h * B - ord(s[i - 1]) * pw + ord(s[i + L - 1])) % MOD
            if h in seen and s[seen[h]:seen[h] + L] == s[i:i + L]:
                return i               # compare text too, in case of a collision
            seen.setdefault(h, i)
        return -1

    lo, hi, start, best = 1, n - 1, 0, 0
    while lo <= hi:                    # repeats of length L exist for L <= answer
        mid = (lo + hi) // 2
        i = find(mid)
        if i >= 0:
            start, best, lo = i, mid, mid + 1
        else:
            hi = mid - 1
    return s[start:start + best]
```

```python
def count_distinct(s: str) -> int:
    n = len(s)
    sa = sorted(range(n), key=lambda i: s[i:])   # simple build; O(n² log n) worst case
    rank = [0] * n
    for r, i in enumerate(sa):
        rank[i] = r
    total, lcp = n * (n + 1) // 2, 0             # every prefix of every suffix
    for i in range(n):                           # Kasai: lcp drops by at most 1 per step
        if rank[i] == 0:
            lcp = 0
            continue
        j = sa[rank[i] - 1]                      # the suffix just before i in sorted order
        while i + lcp < n and j + lcp < n and s[i + lcp] == s[j + lcp]:
            lcp += 1
        total -= lcp                             # these prefixes were already counted
        lcp = max(lcp - 1, 0)
    return total
```

A wildcard such as "." may be any letter, so you try every child with DFS and succeed if any branch works. This is faster than scanning every word because each branch only continues where a real word still exists.

```python
class WordDictionary:
    def __init__(self):
        self.root: dict = {}

    def addWord(self, word: str) -> None:
        node = self.root
        for c in word:
            node = node.setdefault(c, {})
        node["$"] = True               # marks the end of a word

    def search(self, word: str) -> bool:
        def dfs(i: int, node: dict) -> bool:
            if i == len(word):
                return "$" in node
            c = word[i]
            if c == ".":               # wildcard: try every child
                return any(dfs(i + 1, child)
                           for k, child in node.items() if k != "$")
            return c in node and dfs(i + 1, node[c])
        return dfs(0, self.root)
```

```python
def mex(values: set[int]) -> int:      # smallest whole number not in the set
    m = 0
    while m in values:
        m += 1
    return m

def grundy_subtraction(n: int, moves: list[int]) -> int:
    g = [0] * (n + 1)                  # Grundy numbers when you may take any amount in moves
    for i in range(1, n + 1):
        g[i] = mex({g[i - m] for m in moves if m <= i})
    return g[n]

def nim_game(piles: list[int]) -> bool:
    x = 0
    for p in piles:
        x ^= p                         # Grundy number of a pile of size p is p
    return x != 0                      # non-zero XOR: the first player can win
```

@@ matexp
what: If each step of a recurrence is a fixed linear combination of the last k values, write one step as a k by k matrix M. Then n steps equal M raised to the n-th power. Raise it by repeated squaring, so you do about log n matrix multiplications instead of n steps. The time is O(k^3 log n), which is fast when k is small and n is huge.
signals: n is huge, such as 10^9 or 10^18 ; the next state is a fixed linear mix of the current state ; "after t transformations or steps" ; small number of states, such as 26 letters ; answer is asked modulo 10^9 + 7

```python
def length_after_transformations(s: str, t: int, nums: list[int]) -> int:
    MOD, k = 10**9 + 7, 26
    M = [[0] * k for _ in range(k)]
    for i in range(k):
        for d in range(1, nums[i] + 1):    # letter i becomes the next nums[i] letters
            M[i][(i + d) % k] += 1

    def mul(A: list[list[int]], B: list[list[int]]) -> list[list[int]]:
        return [[sum(A[i][l] * B[l][j] for l in range(k)) % MOD
                 for j in range(k)] for i in range(k)]

    R = [[int(i == j) for j in range(k)] for i in range(k)]   # identity matrix
    while t:                                # fast power: M ** t
        if t & 1:
            R = mul(R, M)
        M = mul(M, M)
        t >>= 1
    cnt = [0] * k
    for ch in s:
        cnt[ord(ch) - 97] += 1
    return sum(cnt[i] * sum(R[i]) for i in range(k)) % MOD
```

@@ intervalmap
what: Keep the non-overlapping intervals in a sorted structure keyed by their start. When a new number arrives, a binary search finds the interval just before it and the interval just after it. You then extend or merge at most two neighbours, instead of sorting or scanning all intervals again. Python has no built-in sorted map, so a sorted list with bisect plays that role here.

```python
from bisect import bisect_left

class SummaryRanges:
    def __init__(self):
        self.iv: list[list[int]] = []          # sorted, disjoint [start, end]

    def addNum(self, value: int) -> None:
        iv = self.iv
        i = bisect_left(iv, [value])           # first interval with start >= value
        if i > 0 and iv[i - 1][1] >= value:    # already inside the left neighbour
            return
        if i < len(iv) and iv[i][0] == value:  # already the start of the right one
            return
        left = i > 0 and iv[i - 1][1] == value - 1
        right = i < len(iv) and iv[i][0] == value + 1
        if left and right:                     # value glues two intervals together
            iv[i - 1][1] = iv[i][1]
            del iv[i]
        elif left:
            iv[i - 1][1] = value
        elif right:
            iv[i][0] = value
        else:
            iv.insert(i, [value, value])

    def getIntervals(self) -> list[list[int]]:
        return [x[:] for x in self.iv]
```

@@ lfu
what: An LFU cache evicts the key used the fewest times, and the oldest one among ties. Keep a dictionary from each use count to an ordered list of keys with that count, plus the current minimum count. A use moves a key from bucket f to bucket f+1, and an eviction pops the oldest key of the minimum bucket, so every operation is O(1). A heap would cost O(log n) per update.
signals: "least frequently used" ; evict the key with the lowest use count ; ties broken by least recently used ; get and put must both run in O(1) ; design a cache with a capacity
code:
```python
from collections import OrderedDict, defaultdict

class LFUCache:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.val: dict[int, int] = {}
        self.cnt: dict[int, int] = {}                  # key -> use count
        self.bucket = defaultdict(OrderedDict)         # count -> keys, oldest first
        self.low = 0                                   # smallest count in the cache

    def _touch(self, key: int) -> None:
        f = self.cnt[key]
        del self.bucket[f][key]
        if not self.bucket[f] and self.low == f:
            self.low += 1                              # that bucket is now empty
        self.cnt[key] = f + 1
        self.bucket[f + 1][key] = None                 # newest in its bucket

    def get(self, key: int) -> int:
        if key not in self.val:
            return -1
        self._touch(key)
        return self.val[key]

    def put(self, key: int, value: int) -> None:
        if self.cap == 0:
            return
        if key in self.val:
            self.val[key] = value
            self._touch(key)
            return
        if len(self.val) == self.cap:                  # evict the oldest of the lowest count
            old, _ = self.bucket[self.low].popitem(last=False)
            del self.val[old], self.cnt[old]
        self.val[key], self.cnt[key] = value, 1
        self.bucket[1][key] = None
        self.low = 1                                   # a new key always has count 1
```

```python
from collections import defaultdict

def solve(nums: list[int], queries: list[list[int]]) -> list[int]:
    MOD = 10**9 + 7
    n = len(nums)
    B = int(n ** 0.5) + 1                      # threshold between small and large steps
    ans = [0] * len(queries)
    small = defaultdict(list)                  # step y -> [(x, query index)]
    for qi, (x, y) in enumerate(queries):
        if y >= B:                             # large step: at most n / B terms
            ans[qi] = sum(nums[x::y]) % MOD
        else:
            small[y].append((x, qi))
    for y, qs in small.items():                # one O(n) table per distinct small y
        suf = [0] * (n + y)                    # suf[i] = nums[i] + suf[i + y]
        for i in range(n - 1, -1, -1):
            suf[i] = (nums[i] + suf[i + y]) % MOD
        for x, qi in qs:
            ans[qi] = suf[x]
    return ans
```

```python
def rectangle_area(rectangles: list[list[int]]) -> int:
    MOD = 10**9 + 7
    ys = sorted({y for _, y1, _, y2 in rectangles for y in (y1, y2)})
    idx = {y: i for i, y in enumerate(ys)}
    events = []
    for x1, y1, x2, y2 in rectangles:
        events.append((x1, 1, y1, y2))          # the rectangle starts here
        events.append((x2, -1, y1, y2))         # and ends here
    events.sort()
    m = len(ys) - 1                             # number of elementary y segments
    cnt, cov = [0] * (4 * m), [0] * (4 * m)     # cover count and covered length

    def update(node: int, l: int, r: int, a: int, b: int, v: int) -> None:
        if b <= l or r <= a:
            return
        if a <= l and r <= b:
            cnt[node] += v
        else:
            mid = (l + r) // 2
            update(2 * node, l, mid, a, b, v)
            update(2 * node + 1, mid, r, a, b, v)
        if cnt[node] > 0:
            cov[node] = ys[r] - ys[l]
        elif r - l == 1:
            cov[node] = 0
        else:
            cov[node] = cov[2 * node] + cov[2 * node + 1]

    area, prev = 0, events[0][0]
    for x, v, y1, y2 in events:
        area += cov[1] * (x - prev)             # covered length times the gap
        prev = x
        update(1, 0, m, idx[y1], idx[y2], v)
    return area % MOD
```

what: In a graph where every node has exactly one out-edge, each walk either ends or falls into a cycle. So the graph is cycles with trees hanging into them. Walk from each unvisited node and write a timestamp on every node you pass. If the walk reaches a node stamped in this same walk, you found a new cycle, and its length is the difference of stamps. Each node is visited once.
signals: each node has at most one outgoing edge ; array where edges[i] is the next node ; "follow the pointer" until something repeats ; find the longest or any cycle ; permutation or successor array
code:
```python
def longest_cycle(edges: list[int]) -> int:
    n = len(edges)
    stamp = [0] * n                    # 0 means not visited yet
    best, clock = -1, 1
    for s in range(n):
        if stamp[s]:
            continue
        start = clock                  # stamps from this walk are >= start
        u = s
        while u != -1 and not stamp[u]:
            stamp[u] = clock
            clock += 1
            u = edges[u]
        if u != -1 and stamp[u] >= start:   # we met a node from this very walk
            best = max(best, clock - stamp[u])
    return best
```

signals: minimum height tree or best root ; centre of a tree ; remove leaves round by round ; the answer is one or two nodes ; node degrees matter, such as degree 1

```python
def find_min_height_trees(n: int, edges: list[list[int]]) -> list[int]:
    if n == 1:
        return [0]
    adj = [set() for _ in range(n)]
    for a, b in edges:
        adj[a].add(b)
        adj[b].add(a)
    leaves = [i for i in range(n) if len(adj[i]) == 1]
    remaining = n
    while remaining > 2:               # a tree has at most 2 centres
        remaining -= len(leaves)
        nxt = []
        for leaf in leaves:
            nb = adj[leaf].pop()       # a leaf has exactly one neighbour
            adj[nb].discard(leaf)
            if len(adj[nb]) == 1:      # nb has become a leaf
                nxt.append(nb)
        leaves = nxt
    return leaves
```

```python
from collections import deque

def alien_order(words: list[str]) -> str:
    adj = {c: set() for w in words for c in w}
    indeg = {c: 0 for c in adj}
    for a, b in zip(words, words[1:]):
        for x, y in zip(a, b):
            if x != y:                         # first difference gives one rule x < y
                if y not in adj[x]:
                    adj[x].add(y)
                    indeg[y] += 1
                break
        else:
            if len(a) > len(b):                # "abc" before "ab" is impossible
                return ""
    q = deque(c for c in indeg if indeg[c] == 0)
    out = []
    while q:
        c = q.popleft()
        out.append(c)
        for d in adj[c]:
            indeg[d] -= 1
            if indeg[d] == 0:
                q.append(d)
    return "".join(out) if len(out) == len(adj) else ""   # shorter means a cycle
```

what: In a bipartite graph, a matching pairs left nodes with right nodes so that nobody is used twice. Try each left node in turn. If its wanted partner is free, take it. def maximum_invitations(grid: list[list[int]]) -> int:
```python
    m, n = len(grid), len(grid[0])
    owner = [-1] * n                    # owner[g] = boy currently matched to girl g

    def try_boy(b: int, seen: list[bool]) -> bool:
        for g in range(n):
            if grid[b][g] and not seen[g]:
                seen[g] = True
                # girl is free, or her current boy can move to someone else
                if owner[g] == -1 or try_boy(owner[g], seen):
                    owner[g] = b
                    return True
        return False

    return sum(try_boy(b, [False] * n) for b in range(m))
```

@@ editdist
what: Let dp[i][j] be the fewest edits that turn the first i letters of a into the first j letters of b. If the last letters match, the cost is the same as dp[i-1][j-1]. Otherwise take the cheapest of replace (diagonal), delete (up) or insert (left), and add 1. Only the previous row is needed, so you can keep two rows.
signals: minimum number of edits to turn one string into another ; insert, delete or replace a character ; how similar are two strings ; two strings of length up to 500 ; transform with the fewest operations

```python
def min_distance(word1: str, word2: str) -> int:
    m, n = len(word1), len(word2)
    prev = list(range(n + 1))               # turning "" into word2[:j] needs j inserts
    for i in range(1, m + 1):
        cur = [i] + [0] * n                 # turning word1[:i] into "" needs i deletes
        for j in range(1, n + 1):
            if word1[i - 1] == word2[j - 1]:
                cur[j] = prev[j - 1]        # letters match: no new edit
            else:
                cur[j] = 1 + min(prev[j - 1],   # replace
                                 prev[j],       # delete from word1
                                 cur[j - 1])    # insert into word1
        prev = cur
    return prev[n]
```

@@ lisfast
what: Keep an array tails, where tails[k] is the smallest possible last value of an increasing subsequence of length k+1. This array is always sorted. For each new value, binary search the first tail that is not smaller than it and overwrite that tail, or append when the value is larger than all of them. A smaller tail is never worse, so the array stays useful, and its length is the answer.
signals: longest increasing subsequence with n up to 10^5 ; O(n²) DP is too slow ; nesting or stacking items in two dimensions ; sort one dimension, then find an increasing run in the other ; strictly increasing sequence

```python
from bisect import bisect_left

def max_envelopes(envelopes: list[list[int]]) -> int:
    # width ascending; for equal widths, height descending so they cannot chain
    envelopes.sort(key=lambda e: (e[0], -e[1]))
    tails: list[int] = []
    for _, h in envelopes:
        i = bisect_left(tails, h)      # first tail >= h (strict increase)
        if i == len(tails):
            tails.append(h)            # h extends the longest chain
        else:
            tails[i] = h               # h gives a smaller tail for length i + 1
    return len(tails)
```

what: When the dependencies between states form a directed graph with no cycle, every state depends only on states that come earlier in some order. So you compute each state once, after all the states it needs. You can do this with a topological order, or with a DFS that stores each answer in a memo. This turns an exponential path search into one visit per node.
signals: longest path in a graph with no cycles ; move to a neighbour only if the value is larger ; count the paths from a start to an end ; each state is built from states it points to ; grid moves that must go strictly up or down

```python
import sys
from functools import cache

sys.setrecursionlimit(1 << 16)         # a path can be as long as the grid

def longest_increasing_path(matrix: list[list[int]]) -> int:
    m, n = len(matrix), len(matrix[0])

    @cache
    def dfs(r: int, c: int) -> int:    # longest path that starts at (r, c)
        best = 1
        for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
            if 0 <= nr < m and 0 <= nc < n and matrix[nr][nc] > matrix[r][c]:
                best = max(best, 1 + dfs(nr, nc))
        return best

    return max(dfs(r, c) for r in range(m) for c in range(n))
```

```python
def longest_palindrome_subseq(s: str) -> int:
    n = len(s)
    dp = [[0] * n for _ in range(n)]
    for i in range(n):
        dp[i][i] = 1                          # one letter is a palindrome
    for length in range(2, n + 1):            # short ranges first
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] == s[j]:
                dp[i][j] = dp[i + 1][j - 1] + 2    # both ends join the palindrome
            else:
                dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])  # drop one end
    return dp[0][n - 1]
```

```python
def max_students(seats: list[list[str]]) -> int:
    m, n = len(seats), len(seats[0])
    ok = [sum(1 << j for j in range(n) if seats[i][j] == "." ) for i in range(m)]
    dp = {0: 0}                                   # mask of previous row -> best count
    for i in range(m):
        nd: dict[int, int] = {}
        for mask in range(1 << n):
            if mask & ~ok[i] or mask & (mask << 1):   # broken seat, or two side by side
                continue
            c = bin(mask).count("1")
```

@@ treedp
what: Each node returns a small tuple, with the best value for each state of that node, such as "taken" and "skipped". def rob(root: "TreeNode | None") -> int:
```python
    def dfs(node):
        if not node:
            return (0, 0)                      # (best if taken, best if skipped)
        lt, ls = dfs(node.left)
        rt, rs = dfs(node.right)
        take = node.val + ls + rs              # a taken node forces its children to be skipped
        skip = max(lt, ls) + max(rt, rs)       # a skipped node lets each child choose
        return (take, skip)
    return max(dfs(root))
```

@@ aho
what: Aho-Corasick is a trie of all patterns with a failure link on each node. The failure link points to the longest proper suffix of the node's string that is also in the trie. When the next letter has no edge, follow failure links, like KMP does. Each node also remembers whether it, or any node along its failure links, ends a word. So one pass over the text finds all patterns, with no restart.
signals: many patterns searched in one text or stream ; letters arrive one by one and you ask "does a suffix match a word?" ; the sum of pattern lengths is bounded ; count or find all occurrences of a set of words ; one pattern at a time is too slow
code:

```python
from collections import deque

class StreamChecker:
    def __init__(self, words: list[str]):
        self.nxt: list[dict] = [{}]
        self.fail, self.end = [0], [False]
        for w in words:
            node = 0
            for c in w:
                if c not in self.nxt[node]:
                    self.nxt[node][c] = len(self.nxt)
                    self.nxt.append({})
                    self.fail.append(0)
                    self.end.append(False)
                node = self.nxt[node][c]
            self.end[node] = True
        q = deque(self.nxt[0].values())        # depth-1 nodes keep fail = 0
        while q:
            u = q.popleft()
            for c, v in self.nxt[u].items():
                f = self.fail[u]
                while f and c not in self.nxt[f]:
                    f = self.fail[f]
                self.fail[v] = self.nxt[f].get(c, 0)
                self.end[v] = self.end[v] or self.end[self.fail[v]]
                q.append(v)
        self.cur = 0

    def query(self, letter: str) -> bool:
        while self.cur and letter not in self.nxt[self.cur]:
            self.cur = self.fail[self.cur]     # fall back, like KMP
        self.cur = self.nxt[self.cur].get(letter, 0)
        return self.end[self.cur]
```

@@ trieboard
what: Put all words in a trie, then walk the grid with DFS and move down the trie at the same time. At each cell, continue only if the current trie node has a child for the cell's letter. def find_words(board: list[list[str]], words: list[str]) -> list[str]:
```python
    root: dict = {}
    for w in words:
        node = root
        for c in w:
            node = node.setdefault(c, {})
        node["$"] = w                          # store the whole word at its end
    m, n = len(board), len(board[0])
    res: list[str] = []

    def dfs(r: int, c: int, parent: dict) -> None:
        ch = board[r][c]
        node = parent[ch]
        if "$" in node:
            res.append(node.pop("$"))          # take each word only once
        board[r][c] = "#"                      # mark this cell as used
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < m and 0 <= nc < n and board[nr][nc] in node:
                dfs(nr, nc, node)
        board[r][c] = ch                       # undo
        if not node:
            parent.pop(ch)                     # prune a branch with no words left

    for r in range(m):
        for c in range(n):
            if board[r][c] in root:
                dfs(r, c, root)
    return res
```

@@ patterndp
what: Let dp[i][j] say whether the first i letters of the text match the first j letters of the pattern. A normal letter or "?" needs the previous diagonal cell to match. A star can match nothing, which copies the cell on its left, or it can match one more letter, which copies the cell above. So every cell looks at at most three earlier cells, and no branching search is needed.
signals: match a string against a pattern ; wildcard characters such as ? and * ; regular expression matching ; star means any run of letters ; decide yes or no for the whole string
code:
```python
def is_match(s: str, p: str) -> bool:
    m, n = len(s), len(p)
    dp = [[False] * (n + 1) for _ in range(m + 1)]
    dp[0][0] = True                           # empty text matches empty pattern
    for j in range(1, n + 1):
        if p[j - 1] == "*":
            dp[0][j] = dp[0][j - 1]           # a star can match the empty text
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if p[j - 1] == "*":
                # star matches nothing (left) or one more letter (up)
                dp[i][j] = dp[i][j - 1] or dp[i - 1][j]
            elif p[j - 1] == "?" or p[j - 1] == s[i - 1]:
                dp[i][j] = dp[i - 1][j - 1]
    return dp[m][n]
```

@@ reroot
what: First compute the answer for node 0 with one DFS and count each subtree's size. Then move the root across each edge. When you move from a parent p to a child c, the size[c] nodes in c's subtree get one step closer, and the other n - size[c] nodes get one step farther. So ans[c] = ans[p] - size[c] + (n - size[c]), which is O(1). You never run a new DFS per root.
signals: answer for every node as the root ; sum of distances from each node to all others ; tree with n up to 3 * 10^4 or more ; naive per-root DFS would be O(n²) ; the answer changes in a simple way when the root moves by one edge
code:
```python
def sum_of_distances_in_tree(n: int, edges: list[list[int]]) -> list[int]:
    adj = [[] for _ in range(n)]
    for a, b in edges:
        adj[a].append(b)
        adj[b].append(a)
    parent, order = [-1] * n, [0]
    for u in order:                          # BFS order from root 0
        for v in adj[u]:
            if v != parent[u]:
                parent[v] = u
                order.append(v)
    size, down = [1] * n, [0] * n
    for u in reversed(order):                # children before parents
        p = parent[u]
        if p >= 0:
            size[p] += size[u]
            down[p] += down[u] + size[u]     # all of u's subtree is 1 farther from p
    ans = [0] * n
    ans[0] = down[0]
    for u in order[1:]:                      # parents before children
        ans[u] = ans[parent[u]] - size[u] + (n - size[u])
    return ans
```

@@ splitpoint
what: For a range [i, j], the last piece to be formed or the last cut to be made splits the range at some point k. Try every k and combine the answers of [i, k] and [k, j], plus the cost of the split itself. Fill ranges from short to long so both halves are ready. The idea gives O(n³) time for an O(n²) table, which is fine for n up to 200 to 500.
signals: cut or split a range in the best order ; triangulate a polygon ; multiply a chain of matrices ; burst balloons or remove items in the best order ; the cost of a step depends on both ends of the range
code:
```python
def min_score_triangulation(values: list[int]) -> int:
    n = len(values)
    dp = [[0] * n for _ in range(n)]          # dp[i][j]: best for polygon i..j
    for length in range(2, n):                # j - i = length; 2 is a triangle
        for i in range(n - length):
            j = i + length
            dp[i][j] = min(
                dp[i][k] + dp[k][j] + values[i] * values[k] * values[j]
                for k in range(i + 1, j)      # k is the third corner of the edge i-j
            )
    return dp[0][n - 1]
```

@@ nextperm
what: To get the next larger arrangement, find the last place where the numbers rise, at index i with nums[i] < nums[i+1]. Everything right of i is in falling order, which is the largest arrangement of that tail. Swap nums[i] with the smallest larger number in the tail, then reverse the tail so it becomes the smallest. If no rise exists, the whole array is the largest, so just reverse it.
signals: next larger permutation ; rearrange numbers into the next greater order ; lexicographic order of arrangements ; in place with O(1) extra memory ; wrap around to the smallest order
code:
```python
def next_permutation(nums: list[int]) -> None:
    i = len(nums) - 2
    while i >= 0 and nums[i] >= nums[i + 1]:   # find the last rise
        i -= 1
    if i >= 0:
        j = len(nums) - 1
        while nums[j] <= nums[i]:              # smallest value larger than nums[i]
            j -= 1
        nums[i], nums[j] = nums[j], nums[i]
    l, r = i + 1, len(nums) - 1                # the tail is in falling order
    while l < r:
        nums[l], nums[r] = nums[r], nums[l]
        l, r = l + 1, r - 1
```

@@ duel-ptr
what: Keep two candidate start positions i and j, and a length k of how far they match. Compare letters at i+k and j+k. If one is bigger, the other candidate loses. The loser start, and every start inside the part it already matched, cannot be best, so skip them all by moving the pointer past k. Both pointers only move forward, so the whole scan is linear.
signals: last or largest substring in dictionary order ; smallest rotation of a string ; compare two candidate starts letter by letter ; O(n²) string comparison is too slow ; the answer is always a suffix
code:
```python
def last_substring(s: str) -> str:
    n = len(s)
    i, j, k = 0, 1, 0                      # candidates i and j, matched length k
    while j + k < n:
        if s[i + k] == s[j + k]:
            k += 1
        elif s[i + k] < s[j + k]:          # j is better, so i and its matched part lose
            i = max(i + k + 1, j)
            j = i + 1
            k = 0
        else:                              # i is better, so j and its matched part lose
            j += k + 1
            k = 0
    return s[i:]
```

@@ pointer-switch
what: Two linked lists may join and share a tail. Start one pointer at each head. When a pointer reaches the end, send it to the head of the other list. Each pointer then walks lenA + lenB nodes in total, so both reach the shared start at the same time. If the lists never join, both reach None together. This needs no length counting and no extra memory.
signals: where two linked lists intersect ; two lists with different lengths ; find the common tail without a hash set ; O(1) extra space ; the two pointers must meet at the same distance
code:
```python
def get_intersection_node(headA, headB):
    a, b = headA, headB
    while a is not b:
        a = a.next if a else headB     # after the end, jump to the other list
        b = b.next if b else headA
    return a                           # the meeting node, or None if no overlap
```

@@ lastseen
what: Keep one variable that stores the last index where an event happened. When you see the next event, the distance or the count is a simple subtraction with that stored value. def shortest_distance(words: list[str], word1: str, word2: str) -> int:
```python
    i1 = i2 = -1                       # last index of word1 and of word2
    best = len(words)
    for i, w in enumerate(words):
        if w == word1:
            i1 = i
        elif w == word2:
            i2 = i
        if i1 >= 0 and i2 >= 0:        # both have been seen at least once
            best = min(best, abs(i1 - i2))
    return best
```

@@ median-minimizes
what: The sum of |x - m| over all items is smallest when m is the median. Moving m one step to the right helps the items on the right and hurts the items on the left. The best place is where those two sides are equal, which is the middle. So sort the numbers, take the middle one, and add up the distances to it. You do not need to try every possible target.
signals: make all numbers equal with the fewest moves ; each move changes one number by 1 ; minimise the sum of absolute differences ; best meeting point on a line ; choose a point close to all others
code:
```python
def min_moves2(nums: list[int]) -> int:
    nums.sort()
    med = nums[len(nums) // 2]         # any value between the two middles also works
    return sum(abs(x - med) for x in nums)
```

@@ sort-take
what: When you want to fit as many items as you can into a budget, the smallest items are always the best to take first. The reason it works is that swapping any chosen item for a smaller one never makes things worse.
signals: take as many items as possible within a limit ; maximum count under a total weight or cost ; "how many can you buy or carry?" ; each item has a size and all items are worth the same ; budget, capacity or time is given
code:
```python
def max_number_of_apples(weight: list[int]) -> int:
    weight.sort()                      # lightest apples first
    total = 0
    for i, w in enumerate(weight):
        total += w
        if total > 5000:               # the basket holds at most 5000 units
            return i                   # the first i apples fit
    return len(weight)
```
