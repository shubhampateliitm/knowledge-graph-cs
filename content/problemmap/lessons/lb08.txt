@@ bellman
what: Bellman–Ford finds shortest paths by relaxing every edge again and again. After round r, each distance is the best one that uses at most r edges. Dijkstra breaks when an edge is negative, but this method does not. Limiting the rounds to k + 1 also limits the path to k stops.
signals: "at most k stops" or "at most k edges" ; edge weights can be negative ; "detect a negative cycle" ; a small graph given as a list of edges, not an adjacency list ; shortest path with a hard cap on path length
code:
```python
def find_cheapest_price(n: int, flights: list[list[int]], src: int, dst: int, k: int) -> int:
    INF = float("inf")
    dist = [INF] * n
    dist[src] = 0
    for _ in range(k + 1):          # k stops means at most k + 1 edges
        nxt = dist[:]               # copy: this round may only use last round's values
        for u, v, w in flights:
            if dist[u] + w < nxt[v]:
                nxt[v] = dist[u] + w
        dist = nxt
    return -1 if dist[dst] == INF else dist[dst]
```

@@ binlift
what: Binary lifting stores, for every node, its 1st, 2nd, 4th, 8th ... ancestor in a table. Any jump of k levels is a sum of powers of two, so it takes one table lookup per set bit of k. Walking up one parent at a time costs O(k); this costs O(log k) per query after a one-time build.
signals: "k-th ancestor" of a node, asked many times ; "lowest common ancestor" of many pairs ; many queries on a fixed tree ; jump up a huge number of steps ; "parent array" given
code:
```python
class TreeAncestor:
    def __init__(self, n: int, parent: list[int]):
        self.log = max(1, n.bit_length())
        self.up = [parent[:]]                # up[j][v] = 2^j-th ancestor of v, or -1
        for j in range(1, self.log):
            prev = self.up[-1]
            self.up.append([prev[prev[v]] if prev[v] != -1 else -1 for v in range(n)])

    def getKthAncestor(self, node: int, k: int) -> int:
        j = 0
        while k and node != -1:
            if j >= self.log:
                return -1
            if k & 1:                        # this bit of k is set: jump 2^j levels
                node = self.up[j][node]
            k >>= 1
            j += 1
        return node
```

```python
import heapq

def min_cost(max_time: int, edges: list[list[int]], passing_fees: list[int]) -> int:
    n = len(passing_fees)
    g = [[] for _ in range(n)]
    for u, v, t in edges:
        g[u].append((v, t))
        g[v].append((u, t))
    INF = float("inf")
    best = [[INF] * (max_time + 1) for _ in range(n)]   # best[node][time used]
    best[0][0] = passing_fees[0]
    pq = [(passing_fees[0], 0, 0)]                      # (cost, time, node)
    while pq:
        cost, t, u = heapq.heappop(pq)
        if u == n - 1:
            return cost
        if cost > best[u][t]:
            continue
        for v, w in g[u]:
            nt, nc = t + w, cost + passing_fees[v]
            if nt <= max_time and nc < best[v][nt]:
                best[v][nt] = nc
                heapq.heappush(pq, (nc, nt, v))
    return -1
```

@@ euler
what: An Eulerian path uses every edge exactly once. Hierholzer's method walks along unused edges until it gets stuck. A stuck node must be the end of what is left, so write it down and step back. At the end, the written list is reversed to give the path.

```python
from collections import defaultdict

def find_itinerary(tickets: list[list[str]]) -> list[str]:
    g = defaultdict(list)
    for a, b in sorted(tickets, reverse=True):
        g[a].append(b)                  # smallest destination ends up last
    route, stack = [], ["JFK"]
    while stack:
        while g[stack[-1]]:             # follow unused edges as far as possible
            stack.append(g[stack[-1]].pop())
        route.append(stack.pop())       # stuck: this node is final in the path
    return route[::-1]
```

@@ eulertour
what: Do one DFS and give each node its entry time in order. Every subtree then covers one unbroken range of entry times. "Is a inside the subtree of b?" becomes a check on two numbers, and a subtree total becomes a range sum. This turns tree questions into array questions.

```python
def minimum_score(nums: list[int], edges: list[list[int]]) -> int:
    n = len(nums)
    g = [[] for _ in range(n)]
    for a, b in edges:
        g[a].append(b)
        g[b].append(a)
    parent, order, stack = [-1] * n, [], [0]
    while stack:                         # preorder: order[i] has entry time i
        u = stack.pop()
        order.append(u)
        for v in g[u]:
            if v != parent[u]:
                parent[v] = u
                stack.append(v)
    tin = [0] * n
    for i, u in enumerate(order):
        tin[u] = i
    xr, size = nums[:], [1] * n
    for u in reversed(order[1:]):        # children before parents
        xr[parent[u]] ^= xr[u]
        size[parent[u]] += size[u]
    total, best = xr[0], float("inf")
    inside = lambda a, b: tin[b] <= tin[a] < tin[b] + size[b]   # a is in b's subtree
    for u in range(1, n):
        for v in range(u + 1, n):
            if inside(v, u):
                a, b, c = xr[v], xr[u] ^ xr[v], total ^ xr[u]
            elif inside(u, v):
                a, b, c = xr[u], xr[v] ^ xr[u], total ^ xr[v]
            else:
                a, b, c = xr[u], xr[v], total ^ xr[u] ^ xr[v]
            best = min(best, max(a, b, c) - min(a, b, c))
    return best
```

@@ floyd
what: Floyd–Warshall keeps a table of the best known distance between every pair of nodes. For each node k in turn, ask if going through k is shorter than the current i to j distance.
```python
def find_the_city(n: int, edges: list[list[int]], distance_threshold: int) -> int:
    INF = float("inf")
    d = [[INF] * n for _ in range(n)]
    for i in range(n):
        d[i][i] = 0
    for u, v, w in edges:
        d[u][v] = d[v][u] = min(d[u][v], w)
    for k in range(n):                   # k must be the OUTER loop
        for i in range(n):
            for j in range(n):
                if d[i][k] + d[k][j] < d[i][j]:
                    d[i][j] = d[i][k] + d[k][j]
    best, fewest = -1, INF
    for i in range(n):
        reach = sum(1 for j in range(n) if j != i and d[i][j] <= distance_threshold)
        if reach <= fewest:              # ties go to the larger index
            best, fewest = i, reach
    return best
```

```python
import heapq

def minimum_effort_path(heights: list[list[int]]) -> int:
    rows, cols = len(heights), len(heights[0])
    best = [[float("inf")] * cols for _ in range(rows)]
    best[0][0] = 0
    pq = [(0, 0, 0)]                     # (largest step so far, row, col)
    while pq:
        eff, r, c = heapq.heappop(pq)
        if (r, c) == (rows - 1, cols - 1):
            return eff
        if eff > best[r][c]:
            continue
        for nr, nc in ((r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)):
            if 0 <= nr < rows and 0 <= nc < cols:
                ne = max(eff, abs(heights[nr][nc] - heights[r][c]))   # max, not sum
                if ne < best[nr][nc]:
                    best[nr][nc] = ne
                    heapq.heappush(pq, (ne, nr, nc))
    return 0
```

@@ mst
what: A minimum spanning tree joins all nodes with the smallest total edge cost. Kruskal sorts the edges from cheapest up. It takes an edge only if its ends are in different groups, which union–find checks fast. An edge inside one group would close a cycle, so it is skipped.

```python
def min_cost_connect_points(points: list[list[int]]) -> int:
    n = len(points)
    edges = []
    for i in range(n):
        for j in range(i + 1, n):
            d = abs(points[i][0] - points[j][0]) + abs(points[i][1] - points[j][1])
            edges.append((d, i, j))
    edges.sort()                         # cheapest edges first
    parent = list(range(n))

    def find(x: int) -> int:
        while parent[x] != x:
            parent[x] = parent[parent[x]]   # path halving
            x = parent[x]
        return x

    total = used = 0
    for d, i, j in edges:
        ri, rj = find(i), find(j)
        if ri != rj:                     # joins two parts, so no cycle
            parent[ri] = rj
            total += d
            used += 1
            if used == n - 1:
                break
    return total
```

@@ tarjan
what: Run a DFS and give each node an entry time tin. For each node also keep low, the earliest entry time it can reach using its subtree and one back edge. If a child's low is greater than the parent's tin, the child's side cannot get above the parent, so the edge between them is a bridge.

```python
def critical_connections(n: int, connections: list[list[int]]) -> list[list[int]]:
    g = [[] for _ in range(n)]
    for a, b in connections:
        g[a].append(b)
        g[b].append(a)
    tin, low, timer, bridges = [-1] * n, [0] * n, 1, []
    tin[0] = low[0] = 0
    stack = [(0, -1, iter(g[0]))]        # explicit stack avoids recursion limits
    while stack:
        u, p, it = stack[-1]
        for v in it:
            if v == p:
                continue
            if tin[v] == -1:             # tree edge: go deeper
                tin[v] = low[v] = timer
                timer += 1
                stack.append((v, u, iter(g[v])))
                break
            low[u] = min(low[u], tin[v]) # back edge: reach an older node
        else:                            # all neighbours done: leave u
            stack.pop()
            if stack:
                low[p] = min(low[p], low[u])
                if low[u] > tin[p]:      # u's side cannot climb above p
                    bridges.append([p, u])
    return bridges
```

@@ zeroonebfs
what: When every edge costs 0 or 1, you do not need a heap. Keep a deque. A 0-cost move goes to the front, so it is handled at once at the same distance. A 1-cost move goes to the back. The deque stays sorted by distance, so it acts like Dijkstra in O(V + E).
signals: each move costs 0 or 1 ; "change the direction or sign with cost 1" ; follow the arrow for free, otherwise pay one ; grid with free and paid moves ; "minimum number of changes" to reach a cell

```python
from collections import deque

def min_cost(grid: list[list[int]]) -> int:
    rows, cols = len(grid), len(grid[0])
    dirs = [(0, 1), (0, -1), (1, 0), (-1, 0)]      # signs 1, 2, 3, 4
    dist = [[float("inf")] * cols for _ in range(rows)]
    dist[0][0] = 0
    dq = deque([(0, 0)])
    while dq:
        r, c = dq.popleft()
        for i, (dr, dc) in enumerate(dirs):
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols:
                w = 0 if grid[r][c] == i + 1 else 1   # follow the arrow: free
                if dist[r][c] + w < dist[nr][nc]:
                    dist[nr][nc] = dist[r][c] + w
                    if w == 0:
                        dq.appendleft((nr, nc))
                    else:
                        dq.append((nr, nc))
    return dist[rows - 1][cols - 1]
```

```python
def can_partition_k_subsets(nums: list[int], k: int) -> bool:
    total = sum(nums)
    if total % k:
        return False
    target = total // k
    items = sorted(nums, reverse=True)   # big items first fail fast
    if items[0] > target:
        return False
    fill = [0] * k

    def place(i: int) -> bool:
        if i == len(items):
            return True
        tried = set()
        for b in range(k):
            if fill[b] + items[i] > target or fill[b] in tried:
                continue                 # too full, or same state as a bucket already tried
            tried.add(fill[b])
            fill[b] += items[i]
            if place(i + 1):
                return True
            fill[b] -= items[i]
        return False

    return place(0)
```

@@ coin
what: To make amount a, try every coin as the last one used. The rest is amount a - c, which is already solved. So dp[a] is the smallest dp[a - c] + 1 over all coins. Because coins can be reused, the table is filled from small amounts to large. This is faster than trying all coin combinations.
signals: "fewest coins to make an amount" ; "number of ways to make change" ; each coin can be used any number of times ; "unlimited supply" of items ; return -1 if the target is impossible

```python
def coin_change(coins: list[int], amount: int) -> int:
    INF = amount + 1                     # larger than any real answer
    dp = [0] + [INF] * amount            # dp[a] = fewest coins to make a
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a and dp[a - c] + 1 < dp[a]:
                dp[a] = dp[a - c] + 1
    return dp[amount] if dp[amount] != INF else -1
```

```python
    if total % 2:
        return False

            if reach[s - x]:

    return reach[target]
```

@@ lcs
what: Let dp[i][j] be the answer for the first i characters of one text and the first j of the other. If the last characters match, extend the answer of dp[i-1][j-1] by one. If not, drop one last character and take the better of dp[i-1][j] and dp[i][j-1]. This avoids trying all 2^n subsequences.

```python
def longest_common_subsequence(text1: str, text2: str) -> int:
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]   # dp[i][j]: first i of text1, first j of text2
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]
```

```python
def max_result(nums: list[int], k: int) -> int:
    dp = [0] * len(nums)
    dp[0] = nums[0]
    dq = deque([0])                      # indices; their dp values go down from front to back
    for i in range(1, len(nums)):
        while dq[0] < i - k:             # front is out of the window
            dq.popleft()
        dp[i] = nums[i] + dp[dq[0]]      # front holds the best dp in the window
        while dq and dp[dq[-1]] <= dp[i]:
            dq.pop()                     # worse and older than i: never useful again
        dq.append(i)
    return dp[-1]
```

@@ dpprefix
what: If dp[i][j] is the sum of a range of the previous row, adding that range for every cell is slow. Keep a running sum of the previous row. Moving j right by one adds the new element on the right and removes the one that fell out on the left. Each cell then costs O(1) instead of O(range).
signals: dp value is a sum over a range of the previous row ; "count permutations with exactly k inversions" ; transitions of the form dp[i-1][j-t] for t in a range ; the plain DP is O(n · k · n) and too slow ; counts asked modulo 10^9 + 7
code:
```python
def k_inverse_pairs(n: int, k: int) -> int:
    MOD = 10**9 + 7
    dp = [1] + [0] * k                   # row for 1 number: only 0 inverse pairs
    for i in range(2, n + 1):
        nxt, run = [0] * (k + 1), 0
        for j in range(k + 1):
            run += dp[j]                 # run = dp[j-i+1] + ... + dp[j] via a sliding sum
            if j >= i:
                run -= dp[j - i]
            run %= MOD
            nxt[j] = run
        dp = nxt
    return dp[k]
```

@@ probdp
what: Probability DP spreads chance step by step. Keep a table of the probability of being on each state. For each step, send a share of each state's probability to every state it can move to. The sum of the table at the end is the chance of the event you want. Expected values work the same way.
signals: "probability that ... after k moves" ; each move picks equally among several choices ; "remains on the board" or "survives" ; "expected number of steps" ; the same state can be reached by many paths
code:
```python
def knight_probability(n: int, k: int, row: int, column: int) -> float:
    moves = [(1, 2), (2, 1), (-1, 2), (-2, 1), (1, -2), (2, -1), (-1, -2), (-2, -1)]
    cur = [[0.0] * n for _ in range(n)]
    cur[row][column] = 1.0               # all probability starts on one cell
    for _ in range(k):
        nxt = [[0.0] * n for _ in range(n)]
        for r in range(n):
            for c in range(n):
                if cur[r][c]:
                    for dr, dc in moves:
                        nr, nc = r + dr, c + dc
                        if 0 <= nr < n and 0 <= nc < n:
                            nxt[nr][nc] += cur[r][c] / 8   # each move has chance 1/8
        cur = nxt
    return sum(map(sum, cur))            # mass that never fell off the board
```

@@ submask
what: To visit every subset of a mask, start with sub = mask and repeat sub = (sub - 1) & mask until sub is 0. Subtracting 1 flips the low bits, and the AND with mask keeps only the allowed bits. Each submask appears once. Over all masks, the total work is 3^n, not 4^n.
signals: "all subsets of a set of letters or items" ; mask of up to about 20 bits ; "every letter of the word must be in the puzzle" ; combine two masks that do not overlap ; DP where a state uses the submasks of another state
code:
```python
from collections import Counter

def find_num_of_valid_words(words: list[str], puzzles: list[str]) -> list[int]:
    bit = lambda ch: 1 << (ord(ch) - 97)
    cnt = Counter()
    for w in words:
        m = 0
        for ch in w:
            m |= bit(ch)
        cnt[m] += 1                      # how many words have exactly this letter set
    ans = []
    for p in puzzles:
        first, rest = bit(p[0]), 0
        for ch in p[1:]:
            rest |= bit(ch)
        total, sub = 0, rest
        while True:                      # visits every submask of rest, then 0
            total += cnt[sub | first]    # the first letter is mandatory
            if sub == 0:
                break
            sub = (sub - 1) & rest
        ans.append(total)
    return ans
```

@@ tspdp
what: Some problems ask for a path that visits every node. Let the state be (set of visited nodes as a bitmask, current node). Moves go from one state to the next by stepping along an edge and setting a bit. With equal edge costs, BFS over these states finds the fewest steps. This uses at most 2^n · n states.
signals: "visit every node" with n at most about 12 to 20 ; "shortest path visiting all nodes" ; "travelling salesman" ; may start anywhere and revisit nodes ; need to remember which nodes were already seen
code:
```python
from collections import deque

def shortest_path_length(graph: list[list[int]]) -> int:
    n = len(graph)
    full = (1 << n) - 1
    q = deque((1 << i, i) for i in range(n))       # start anywhere: (visited mask, node)
    seen = {(1 << i, i) for i in range(n)}
    steps = 0
    while q:
        for _ in range(len(q)):          # one BFS level per step
            mask, u = q.popleft()
            if mask == full:
                return steps
            for v in graph[u]:
                state = (mask | (1 << v), v)
                if state not in seen:
                    seen.add(state)
                    q.append(state)
        steps += 1
    return 0
```

@@ kmp
what: The KMP prefix function pi[i] is the length of the longest proper prefix of s[:i+1] that is also its suffix. It is built in one pass: on a mismatch, fall back to the next shorter border, pi[k - 1], instead of starting from zero. The text pointer never moves back, which is what makes it linear.
signals: "longest prefix which is also a suffix" ; "find the pattern in the text" in linear time ; "shortest string with this as a prefix and suffix" ; border or period of a string ; repeated pattern inside a string
code:
```python
def longest_prefix(s: str) -> str:
    n = len(s)
    pi = [0] * n                         # pi[i]: longest proper prefix of s[:i+1] that is also its suffix
    k = 0
    for i in range(1, n):
        while k and s[i] != s[k]:
            k = pi[k - 1]                # fall back to the next shorter border
        if s[i] == s[k]:
            k += 1
        pi[i] = k
    return s[:pi[-1]]
```

@@ manacher
what: Manacher finds the longest palindrome around every centre in O(n). It remembers the palindrome that reaches furthest right. A new centre inside it is the mirror of an earlier centre, so its answer starts from the mirror's answer. Only the part beyond the right edge is checked character by character. Expanding around each centre from scratch is O(n²).
signals: "longest palindromic substring" with n up to 10^5 ; "count all palindromic substrings" fast ; palindrome length known for every centre ; two non-overlapping palindromes ; the O(n²) expand-around-centre is too slow
code:
```python
def max_product(s: str) -> int:
    n = len(s)
    d = [0] * n                          # d[i]: radius of the longest odd palindrome centred at i
    l, r = 0, -1
    for i in range(n):
        k = 1 if i > r else min(d[l + r - i], r - i + 1)   # reuse the mirror image
        while i - k >= 0 and i + k < n and s[i - k] == s[i + k]:
            k += 1
        d[i] = k
        if i + k - 1 > r:
            l, r = i - k + 1, i + k - 1
    end, start = [1] * n, [1] * n        # longest odd palindrome ending / starting at each index
    for i in range(n):
        end[i + d[i] - 1] = max(end[i + d[i] - 1], 2 * d[i] - 1)
        start[i - d[i] + 1] = max(start[i - d[i] + 1], 2 * d[i] - 1)
    for i in range(n - 2, -1, -1):
        end[i] = max(end[i], end[i + 1] - 2)       # trim both ends of a palindrome
    for i in range(1, n):
        start[i] = max(start[i], start[i - 1] - 2)
    pre, suf = end[:], start[:]
    for i in range(1, n):
        pre[i] = max(pre[i], pre[i - 1])
    for i in range(n - 2, -1, -1):
        suf[i] = max(suf[i], suf[i + 1])
    return max(pre[i] * suf[i + 1] for i in range(n - 1))
```
