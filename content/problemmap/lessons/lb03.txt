@@ spiral
what: Keep four bounds: top, bottom, left and right. Walk the top row, then the right column, then the bottom row, then the left column. After each side, move that bound one step inward. This never visits a cell twice and needs no visited grid.
signals: "spiral order" or "clockwise from the outside in" ; walk a matrix layer by layer ; "rotate" or "print" a matrix in a special path ; bounds that shrink after each pass
code:
```python
def spiral_order(matrix: list[list[int]]) -> list[int]:
    if not matrix:
        return []
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    out = []
    while top <= bottom and left <= right:
        for c in range(left, right + 1):        # top row, left to right
            out.append(matrix[top][c])
        top += 1
        for r in range(top, bottom + 1):        # right column, downward
            out.append(matrix[r][right])
        right -= 1
        if top <= bottom:                       # bottom row, right to left
            for c in range(right, left - 1, -1):
                out.append(matrix[bottom][c])
            bottom -= 1
        if left <= right:                       # left column, upward
            for r in range(bottom, top - 1, -1):
                out.append(matrix[r][left])
            left += 1
    return out
```

@@ mergesort
what: Split the array in half. Sort each half the same way, by recursion. Then merge the two sorted halves by always taking the smaller front item. Merging is linear, and there are about log n levels of splitting. So the total is O(n log n), even in the worst case.

code:
```python
def sort_array(nums: list[int]) -> list[int]:
    if len(nums) <= 1:                  # base case: already sorted
        return nums
    mid = len(nums) // 2
    left = sort_array(nums[:mid])
    right = sort_array(nums[mid:])
    out, i, j = [], 0, 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:         # "<=" keeps equal items in order
            out.append(left[i]); i += 1
        else:
            out.append(right[j]); j += 1
    out.extend(left[i:])                # one side is empty; copy the rest
    out.extend(right[j:])
    return out
```

```python
        # p[r][c] = sum of matrix[0..r-1][0..c-1]; row 0 and column 0 are zeros
        self.p = [[0] * (n + 1) for _ in range(m + 1)]
        for r in range(m):
            for c in range(n):
```

```python
    n = len(nums)
    left = [0] * n           # left[i] = sum of nums[0..i-1]

    for i in range(n - 2, -1, -1):

    for i in range(n):
```

@@ varwin
what: Move the right end one step at a time to take in new items. If the window becomes invalid, move the left end forward until it is valid again. Each item enters once and leaves at most once. So the window sweeps the array in linear time, and you record the best size when it is valid.
signals: "longest substring" or "subarray" with a condition ; "at most k" distinct, or "no repeating" ; the window is valid or invalid as items are added ; all values are non-negative, or the condition only gets worse as it grows ; shortest window that meets a limit
code:
```python
def length_of_longest_substring(s: str) -> int:
    seen: set[str] = set()      # letters inside the window s[left..right]
    left = best = 0
    for right, ch in enumerate(s):
        while ch in seen:       # invalid: shrink from the left until valid
            seen.remove(s[left])
            left += 1
        seen.add(ch)
        best = max(best, right - left + 1)
    return best
```

@@ cycle-entry

```python
        fast = fast.next.next

            while p is not slow:       # both walk one step to the entry

                slow = slow.next
```

@@ dll
what: Give every node both a prev and a next pointer. Add a dummy head and a dummy tail that hold no data. ```python

```python
    def __init__(self, val: int = 0):
        self.val, self.prev, self.next = val, None, None

class MyLinkedList:
    def __init__(self):
        self.head, self.tail, self.size = Node(), Node(), 0   # sentinels
        self.head.next, self.tail.prev = self.tail, self.head

    def _node_at(self, i: int) -> Node:      # i == size gives the tail sentinel
        cur = self.head.next
        for _ in range(i):
            cur = cur.next
        return cur

    def get(self, index: int) -> int:
        return self._node_at(index).val if 0 <= index < self.size else -1

    def addAtHead(self, val: int) -> None:
        self.addAtIndex(0, val)

    def addAtTail(self, val: int) -> None:
        self.addAtIndex(self.size, val)

    def addAtIndex(self, index: int, val: int) -> None:
        if not 0 <= index <= self.size:
            return
        nxt = self._node_at(index)
        node, prv = Node(val), nxt.prev
        node.prev, node.next, prv.next, nxt.prev = prv, nxt, node, node
        self.size += 1

    def deleteAtIndex(self, index: int) -> None:
        if 0 <= index < self.size:
            node = self._node_at(index)
            node.prev.next, node.next.prev = node.next, node.prev
            self.size -= 1
```

@@ rpn
what: In postfix notation, the operator comes after its two numbers. Read the tokens from left to right. Push each number on a stack. When you see an operator, pop two numbers, apply it, and push the result. At the end, one number is left. You never need brackets or operator priority.

```python
def eval_rpn(tokens: list[str]) -> int:
    ops = {
        "+": lambda a, b: a + b,
        "-": lambda a, b: a - b,
        "*": lambda a, b: a * b,
        "/": lambda a, b: int(a / b),    # division truncates toward zero

    st: list[int] = []
    for t in tokens:
        if t in ops:
            b = st.pop()                 # the right operand is on top
            a = st.pop()
            st.append(ops[t](a, b))
        else:
            st.append(int(t))            # "-3" is a number, not an operator
    return st[0]
```

```python
    while lo <= hi:
        mid = (lo + hi) // 2
        v = matrix[mid // n][mid % n]      # flat index -> (row, column)
        if v == target:
            return True
        if v < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return False
```

@@ bstprop
what: In a binary search tree, all keys in the left subtree are smaller than the node, and all keys in the right subtree are larger. So one comparison tells you which side the target is on. You discard the other whole subtree. This is binary search on a tree, and it takes time proportional to the height.
signals: "binary search tree" and a value to find ; insert, delete or search by key ; "closest value" or range in a BST ; validate a BST ; inorder gives sorted order
code:
```python
class TreeNode:
    def __init__(self, val: int = 0, left: "TreeNode | None" = None, right: "TreeNode | None" = None):
        self.val, self.left, self.right = val, left, right

def search_bst(root: "TreeNode | None", val: int) -> "TreeNode | None":
    while root and root.val != val:
        # smaller keys are on the left, larger keys on the right
        root = root.left if val < root.val else root.right
    return root          # the matching node, or None if we fell off the tree
```
